<evidence_note>
The new route is based on official GitHub REST docs for version 2022-11-28: `GET /user` supplies the authenticated account login, and `GET /repos/{owner}/{repo}/collaborators/{username}/permission` returns that user's role with repository Metadata read permission. GitHub maps `maintain` to write and `triage` to read. See https://docs.github.com/en/rest/users/users?apiVersion=2022-11-28 and https://docs.github.com/en/rest/collaborators/collaborators?apiVersion=2022-11-28. These sources document the endpoint contract only; the live result must come from this exact approved preflight.
</evidence_note>
