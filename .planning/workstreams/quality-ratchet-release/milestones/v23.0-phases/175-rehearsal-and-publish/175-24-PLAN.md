<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Downloaded workflow artifacts -> evidence adapter | Potentially stale, incomplete, duplicated, oversized, or malformed bytes cross into canonical receipt production. |
| Dispatch identity/run IDs -> trusted attestation job | Caller-selected identifiers must bind to the exact live workflow runs and candidate OIDs, not grant authority by themselves. |
| Maven credentialed rehearsal -> durable artifact | The workflow exercises real credentials but only redacted closed results may leave the job. |
| Produced receipt -> canonical artifact store | Repository-generated bytes become merge-guard authority only after independent exact-evidence validation. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-175-24-01 | Spoofing | Candidate/run binding | critical | mitigate | Require exact version/base/head/tree plus four positive run IDs; compare each downloaded artifact and live workflow metadata independently. |
| T-175-24-02 | Tampering | Evidence directory | high | mitigate | Closed filenames/maps, byte-size bounds, symlink rejection, digest recomputation, exact rosters, and seed-red missing/stale fixtures. |
| T-175-24-03 | Elevation of Privilege | Attestation dispatch | critical | mitigate | Remove caller-supplied canonical bytes; keep actions/contents read-only and prohibit merge/publish/recovery/authorization operations structurally. |
| T-175-24-04 | Repudiation | Canonical receipt provenance | high | mitigate | Bind exact run/workflow identities and artifact digests into the receipt and exact-head artifact name; independently revalidate before upload. |
| T-175-24-05 | Information Disclosure | Maven and malformed evidence | high | mitigate | Persist closed normalized fields only; generic non-echoing errors; privacy canary tests; exclude deployment IDs, logs, bodies, headers, tokens, and signing data. |
| T-175-24-06 | Denial of Service | Artifact parsing | medium | mitigate | Reject oversized inputs and unexpected cardinality before decoding/normalization. |
