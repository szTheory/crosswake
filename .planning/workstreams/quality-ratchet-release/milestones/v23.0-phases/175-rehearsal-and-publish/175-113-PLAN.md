<evidence_note>
The path is supported by current official GitHub REST documentation for API version 2022-11-28:

- `GET /user` returns the authenticated account's login; GitHub documents no additional fine-grained token permission for this endpoint: https://docs.github.com/en/rest/users/users?apiVersion=2022-11-28
- `GET /repos/{owner}/{repo}/collaborators/{username}/permission` returns that account's repository role and supports a fine-grained token with repository Metadata read: https://docs.github.com/en/rest/collaborators/collaborators?apiVersion=2022-11-28
- GitHub maps `maintain` to write and `triage` to read. These documentation facts establish the shape of a different check; they do not establish the current mirror role or any present release readiness.
</evidence_note>
