<objective>
Retire the version-welded display names and make duplicate-name detection actually able to find a
duplicate.

Purpose: today's duplicate detection is vacuous by construction — `list_merge_blocking_checks.py`
only dedupes names containing the substring `merge-blocking`, which post-v22.0 matches only
de-registered legacy names, so the one real collision in the tree slips straight through. That is
the exact named defect this milestone fights. Meanwhile three release job names and two artifact
names carry a frozen version literal that will be wrong the moment the version moves.

assertion in the shell entry point, and fixture-based proof that each new assertion fires.
