def validate_adoption_claim!(claim) when is_map(claim) do
  violations =

    |> require_closed(claim, :source_binding, @source_bindings)

## Shared Patterns

### Fail closed; absence is never success
**Source:** `script/bearings_report.exs` header (lines 3-13), `test/crosswake/guides/unreleased_claim_qualifier_test.exs:59-67` and `test/crosswake/contract/contract_drift_test.exs:100-103`

Every check needs (a) a non-empty floor assertion (the thing it scans exists and matched at least once), (b) a mutation or synthetic input that turns it red, asserted on the specific reason, (c) an `UNVERIFIED`/named-reason path on any read failure instead of a pass. Controls that mutate text must raise if the mutation changed nothing (`unreleased_claim_qualifier_test.exs:91-93`).

### Idempotent generate and compare
**Source:** `lib/mix/tasks/crosswake.contract.gen.ex:571-593` (`write_if_changed/2`), `lib/crosswake/capability_map/renderer.ex:101-121` (`write/2`), `lib/mix/tasks/crosswake.docs.sync.ex:38-73` (`--check`)
**Apply to:** the two constant files, `guides/parity_ledger.md`.
Generated bytes are produced by one function, written only if different, and compared in memory by `--check` (CI step `mix crosswake.docs.sync --check` in `documentation-contracts`, `crosswake-ci.yml` ~line 122). Never hand-edit; regenerate with `mix crosswake.contract.gen && mix crosswake.docs.sync`.

### Closed-vocabulary validators that raise without echoing data
**Source:** `lib/crosswake/capability_map.ex:609-663`
**Apply to:** `SupportMatrix.validate_android_evidence!/1`, `ParityLedger` validation.
Accumulate rule names, raise `ArgumentError, "invalid <thing>: rule1, rule2"`; the message never contains caller data.

### Privacy
**Source:** AGENTS.md "Sensitive Data Rules"; `BridgeChannel.deny` (`BridgeChannel.kt:325-351`) emits `payload: {}`.
**Apply to:** ledger text, evidence JSON, boundary tests.
No adopter identity (use "first adopter" if at all), no raw payloads, tokens, account or stable device identifiers in any proof artifact; the evidence JSON carries only version, head SHA, counts, reason and blob hash (D-20). Run the privacy scan before every push (AGENTS.md).
