`clean-room-proof-*` lanes in `release-please.yml` — not their `needs:`, not their `if:`, not their
invocation. The rehearsal is a second door onto the same script, never a replacement for the lane,

<objective>
Turn the clean-room proof from something that only runs after a publish into something an operator
can run on demand, then actually run it against the live published `crosswake_rindle 0.1.0` and
record what happened.

Purpose: ROADMAP Success Criteria 3 and 4 both explicitly refuse code inspection as evidence. SC#3
wants a green CI run; SC#4 wants a captured log grepped for parity. Today neither is obtainable
without cutting a release, which is exactly why the lane has been red across three publishes without
anyone being able to cheaply check a fix.

Output: a dispatchable rehearsal lane, a recorded run id and conclusion for rindle, two captured
logs, and a measured marker-parity fact.
</objective>
