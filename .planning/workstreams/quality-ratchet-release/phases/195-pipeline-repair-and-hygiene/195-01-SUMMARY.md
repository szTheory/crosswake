- **Found during:** Task 2
- **Issue:** On this Mac, with the release patch applied, `IOSHostMigrationSecurityTest` (2 tests) fails because `xcodebuild -showBuildSettings` cannot resolve `crosswake-shell-core-ios 0.2.12..<1.0.0`: the 0.2.12 mirror tag does not exist until the release is published. - **Fix:** No test change (normalizing would hide a real resolve failure). The full suite and the matrix were rehearsed with `xcodebuild` removed from PATH to match CI: rc 0. The head run (rc 0, 2758 tests) ran with `xcodebuild` present.
- **Note:** One earlier combined rehearsal (full suite, then matrix, back to back) reported 2 matrix failures that I could not identify because the script prints only the last 80 log lines. Two later matrix runs with the same patch and PATH passed (rc 0 and the final eh3 run, all six passes). Treat the first as an unexplained one-off.

**3. [Acceptance wording] `grep -c 'VersionStamp.normalize_stamp'` in the gen-shell test is 1 line, not 3**
- The three golden comparisons share one `assert_matches_golden/1` helper that does the normalization once; every golden comparison in the file goes through it.
