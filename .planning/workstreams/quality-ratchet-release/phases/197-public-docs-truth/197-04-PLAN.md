`docs_parse` (awk, dependency-free, D-01): for README.md the scope is the lines after the heading `### Integrating Crosswake` up to the next `### ` or `## ` heading; for guides/install.md the whole file. Track fences with the same rule as `strip_fences/1` (a trimmed line starting with three backticks toggles). For each fence, the nearest preceding non-blank line must match `^<!-- cleanroom:(run|apply|clone|show)( [a-z_]+=[^ ]+)* -->$`; otherwise `fail docs "parse unmarked_fence <file>"`. Emit one record per fence into `$WORK/docs/steps.tsv` (file, ordinal, kind, id, attributes) and write the body to `$WORK/docs/body/<file-tag>-<ordinal>`. A `run`, `apply` or `clone` marker without `id=`, a duplicate id across both files, or an unknown attribute is `parse <reason>` (`missing_id`, `duplicate_id`, `unknown_attr`). Allowed attributes: `id`, `file`, `mode`, `since`. An `apply` record is accepted by the parser in this task but `leg_docs` fails it with `parse apply_unsupported` until 197-05 implements it.

`docs_make_host` (D-02): `need_tools docs curl awk sed grep tr head tail cut mktemp mkdir rm cp tar gzip mix` first. Create `$WORK/home`, `$WORK/mix_home`, `$WORK/hex_home`. Under the scrubbed env run `mix local.hex --force`, `mix local.rebar --force`, `mix archive.install hex phx_new "$PHX_NEW_VERSION" --force`, then `mix phx.new "$WORK/host-template" --app clean_room_host --module CleanRoomHost --no-ecto --no-dashboard --no-mailer --no-gettext --no-install --no-version-check` (assets ENABLED: no `--no-assets`, D-02); write the toolchain `.tool-versions` exactly as `leg_hex` does when both selectors are set. If `phx_new 1.8.13` cannot be installed or run under the toolchain, pick the newest `1.8.x` that works, set `PHX_NEW_VERSION` to it and record the reason in the summary. For each doc file, copy the template to a fresh `$WORK/host-<file-tag>` so README and install.md are each proven on their own host (both files must carry the wiring, SC1). Any failure here is `fail docs tool_unavailable`.

`docs_env`: run every documented step as `env -i PATH="$PATH" LANG="${LANG:-C.UTF-8}" HOME="$WORK/home" MIX_HOME="$WORK/mix_home" HEX_HOME="$WORK/hex_home" MIX_ENV=dev ASDF_DIR=... ASDF_DATA_DIR=...` where the two asdf variables are passed only when set in the caller (ASDF_DATA_DIR defaulting to the caller's `$HOME/.asdf` when that directory exists, so shims still resolve under the new HOME). No other variable crosses. `docs_run_step`: write the body to `$WORK/docs/steps/<id>.sh` and run `bash -e <file>` with cwd at that file's host, output appended to `$WORK/docs.log` (never echoed: the existing legs print fixed lines only); non-zero exit is `fail docs "step <id> exit <code>"` and stops that file's sequence. `clone` and `show` blocks are counted (`clone=`, `shown=`) and never executed. After both files: `cleanroom: leg docs PASS $VERSION executed=<n> not_applicable=0 clone=<n> shown=<n> source=commit:<ref> phx_new=$PHX_NEW_VERSION` (the `not_applicable` and floor rules are filled in 197-05).

Tests (hermetic, `async: false`; add `CLEANROOM_DOCS_REF`, `CLEANROOM_DOCS_BASE`, `CLEANROOM_KEEP_WORK` to `@selftest_env`): build a docs base `<root>/docs/<40 zeros>/README.md` and `.../guides/install.md` containing only `run`, `clone` and `show` blocks, and a PATH-first `mix` stub (bash) that handles `local.hex`, `local.rebar`, `archive.install`, `phx.new <dir>` (creates `<dir>/mix.exs`), `deps.get`, `crosswake.install`, `crosswake.doctor` (exit 0) and exits 1 printing `The task "<name>" could not be found` for anything else; the stub also appends `env` output to an absolute path baked into the stub so the test can read it.
