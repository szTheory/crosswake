### Per-mode target, anchor and idempotence rules (addresses review concern 197-06 per-mode anchors)

| Mode | Target file must | Anchor | Idempotence rule | Failure reasons |
|---|---|---|---|---|
| `create` | not exist, or exist with identical content | none | identical existing content is a no-op | `exists` (file present with different content) |
| `append` | exist | none | skipped when the exact body is already present in the file | `target_missing` |
| `deps` | exist (`mix.exs`) | the line containing `defp deps do` followed by a line holding `[` | a tuple whose `:name` is already in the deps list is left alone | `target_missing`, `anchor_missing` |
| `esbuild-args` | exist (`config/config.exs`) | the first `~w(js/app.js` sigil | a `--` token already present (or `--name=` already present for `--name=value`) is skipped | `target_missing`, `anchor_missing` |
| `js-hook` | exist (`assets/js/app.js`) | the first `hooks: {` (the import lines need no anchor; they are prepended) | an import line already present, or `CrosswakeBridge` already in the hooks object, is skipped | `target_missing`, `anchor_missing` |
| `router-route` | exist (the router file) | the first `pipe_through :browser` line inside the first `scope "/", ` block | a body line already present is skipped | `target_missing`, `anchor_missing` |

`create` makes missing parent directories inside the host only after the `bad_path` guard passes. No mode ever writes outside the per-file host directory.
