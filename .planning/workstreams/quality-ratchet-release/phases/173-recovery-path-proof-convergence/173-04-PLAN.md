output in the committed record is what outlives them, which is the same reasoning that put the

branch-scoped dispatch because the new operation option is not yet present on the default branch,

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Fire-drill job -> the real recovery proof body | The drill stands in for the recovery lane only if it reaches the identical body by the identical path |
| GitHub Actions runtime -> the recorded conclusion | The distinction between failure and skipped is decided by the platform, not by anything in this repository |
| Executor -> phase-close verifier | The verifier cannot re-run a mutation against a tree that no longer exists; the record is the only durable evidence |

| T-173-18 | Repudiation | A "not skipped" assertion made vacuously true by a job absent from the run's job list | high | mitigate | Task 2b requires asserting the job's presence in the list as a separate fact from its conclusion value. |
