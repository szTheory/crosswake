## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Absence scored as success | The milestone's defining defect. `check-actions` reported `mutable_refs=0` while scanning ~12% of its claimed scope (fixed in Wave 0 — now `files=27 actions=252 mutable_refs=0`). | blocking | Every new check must be driven RED on a seeded violation before its green is trusted, and must fail when its own scope is empty or has shrunk (see `assertFullScope` in `scripts/ci_monitor.cjs` and the exit-3 roster guard in `script/check_release_doc_version_literals.exs`). |
| Vacuously red check | Inverse of the above, found this session and NOT yet fixed. `lockstep-truth` in `release-please.yml` fails unconditionally: its `sed` expects `@version "X" # x-release-please-version` on one line, but `mix.exs` has the annotation on line 4 and `@version` on line 5, so extraction yields the comment text. All real coordinates are consistent at `0.2.1`. | blocking | Fix the extraction to read the line *after* the annotation, then prove it detects a genuine mismatch before trusting its green. |
| Diagnostics discarded at the pipe | The Maven fire drill pipes the Portal status response into `python3 … .get('deploymentState','')`, throwing away the `errors` array. It can report failure but never the reason. | advisory | Capture the full response body; print `errors` on FAILED. |
| Pipe masks exit code | `cmd \| tail && echo OK` reports the tail's status, so a gate reports green while asserting nothing. Standing repo rule. | blocking | Read `$?` directly. Redirect large output to a file and grep it. (The fire-drill step does correctly set `set -euo pipefail`.) |
| Trusting subagent reports unverified | Subagents reported accurately this session, but two of my own orchestrator-level measurements were wrong and were caught by a subagent re-checking them (an `xargs grep -o` that silently dropped a filename; a diff-confinement check run against `origin/main` instead of the real merge). | advisory | Re-verify any number before it enters an artifact. |
