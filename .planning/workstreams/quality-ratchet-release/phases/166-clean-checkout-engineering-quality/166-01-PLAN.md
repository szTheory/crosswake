## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI arguments → runner | User input may select a fixed stage but must never become executable command text. |
| stage manifest → child process | Repository configuration becomes argv/cwd/env and must remain closed and validated. |
| local inventory → CI source | Local PASS must not spoof or mutate CI authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-166-01 | Tampering / Elevation of privilege | facade and runner argv | high | mitigate | Fixed flags, closed argv arrays, no shell evaluation, cwd containment tests. |
| T-166-02 | Spoofing | stage-to-CI parity | high | mitigate | Literal owner and command parity against tracked workflow/manifest; no GitHub writes. |
| T-166-03 | Information disclosure | preflight diagnostics | high | mitigate | Allowlisted tool facts only; never environment values, secrets, or child payloads. |
| T-166-04 | Denial of service | malformed dependency graph | medium | mitigate | Cycle/unknown-dependency rejection before execution and bounded self-tests. |
</threat_model>
