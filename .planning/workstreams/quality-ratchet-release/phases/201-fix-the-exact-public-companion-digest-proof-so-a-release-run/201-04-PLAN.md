## Why the core is measured at the 0.2.13 head, not the fix head

The core's payload includes `lib/crosswake/release_candidate/artifact.ex`, so a core built at the fix head is not
the published 0.2.13 content. Every candidate build here runs `hex_artifacts.sh` in a detached worktree at the 0.2.13
approved head `5a6a752185cc557af30b0f87244b8088ac83ff93`. Companions build from their own tag commits through
`package_source_ref.sh` regardless. Only the inspector changes. The old rule is that worktree's `Artifact`; the new
rule is the fix branch's `Artifact` in `~/projects/crosswake-201-wt`. The old 0.2.13 approved receipt uses
the old rule, so it cannot be compared with new-rule digests (research Pitfall 3); it is used only for M1 and M1b.
Under the companions-only rule (PD-01), the core's new-rule digest equals its old-rule digest. M2 therefore matches on
the core because Hex 2.7.0 built both sides, and M3 must show the core differing when Hex 2.5.1 builds the candidate.

## Script contracts (phase-local one-time reconciliation helpers, not CI gates; bash 3.2 compatible)

- `scripts/inspect-family-201.sh --inspector <checkout> --refs <manifest.json> --tarballs <dir> --output-root <new dir>`:
  - Reads package, version and candidate_ref for the six packages, in `Artifact.packages/0` order, from `--refs` (a six-entry observation array).
  - Requires exactly one `<package>-<version>.tar` per package in `--tarballs`.
  - Copies each into `<output-root>/tarballs/`, unpacks it into `<output-root>/unpacked/<package>` with the same `:mix_hex_tarball.unpack/2` call `matrix_fetch_public_family` uses, and computes its sha256. It writes `<output-root>/tarballs.sha256` (one `<sha256>  <file>` line per tarball).
  - Then runs once, in the inspector checkout, `mix run --no-start -e 'Crosswake.ReleaseCandidate.Artifact.inspect_cli!(System.argv())' --` with `<output-root>`, `<output-root>/manifest.json` and the six 7-field groups (source `built_tarball`). Stdout is discarded and stderr goes to `<output-root>/inspect.stderr`.
  - Uses the caller's `MIX_HOME`/`HEX_HOME`. Exit 0 manifest written, 1 inspection or unpack failed, 2 usage or missing input. Refuses an existing non-empty `--output-root`.
- `scripts/compare-manifests-201.sh <A.json> <B.json>`:
  - For each of the six packages prints `compare: package=<p> metadata=<equal|differ> payload=<equal|differ>`.
  - Then prints `compare: metadata_equal=<n>/6 payload_equal=<n>/6 verdict=<EQUAL|DIFFER>`.
  - Exit 0 EQUAL (6/6 and 6/6), 1 DIFFER, 2 when either file is unreadable, not exactly six entries, or missing a package or digest field.
