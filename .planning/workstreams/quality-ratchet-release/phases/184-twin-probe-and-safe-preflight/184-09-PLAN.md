<gap_decisions>
Task 4 records these as D-35 and D-36 in 184-CONTEXT.md, in the section "Gap-closure amendments (2026-10-15)" after D-34.

- D-35: exact parsing and exact trust. It amends the 184-07 WR-01 design and closes GAP-CR-01, GAP-WR-01 and GAP-IN-01.
  (a) List ignored untracked paths with ls-files --others --ignored --exclude-standard -z and no directory collapsing. Every listed entry is then a file (or the root of a nested repository) and is judged on its own. Correctness no longer depends on whether a git version lists the members of a collapsed folder. Checked during planning on git 2.41.0 against the real candidate (read-only): 9185 entries, every deciding source is the tracked root .gitignore, and one check-ignore pass took 0.2 s, so the uncollapsed listing is affordable. The @max_dirty_count bound on the listing stays.
  (b) Resolve the deciding rules with one call: check-ignore --verbose --non-matching --stdin -z. git 2.41 rejects -z without --stdin (checked during planning: "-z only makes sense with --stdin", exit 128). run_git has no stdin, so the paths go into a NUL-separated file in the private temporary index directory that with_private_index already makes (0700, absolute, shown to be outside the candidate, its git dir and the run root, and removed afterwards). The file is written with File.write and exclusive create. The builder gains one stdin form whose shell script redirects stdin from its first positional argument. The file path is an argv element, never script text, and is included in the NUL refusal check. The 200-entry argv batching is removed because stdin has no argv limit.
  (c) Parse the output only by splitting on NUL, as two separate checks, each with its own test, so each check can be shown load-bearing on its own. First the framing check: the output ends in NUL and has exactly four fields (source, line number, pattern, path) per sent entry, no more and no fewer. Then group the fields into records, pair them with the entries using Enum.zip, and run the path-binding check: each record's path must equal, byte for byte, the entry sent at that position. The line number is empty exactly when the source is empty, and otherwise all digits. Anything else is :unavailable. No field is ever split on a colon or unquoted. Checked during planning: under -z, git prints the source of a .gitignore in a folder named we"ird without quotes.
  (d) Trust a rule source only in two cases. (i) Path.expand(source, candidate) equals Path.expand of the trimmed output of rev-parse --git-path info/exclude; those rules are counted by excludes (D-03). (ii) Path.basename(source) is .gitignore and the source is exactly an entry of the fresh HEAD index (exact MapSet membership of the raw string). Every other source, including an empty one, counts as one modified finding. Checked during planning with raw git: the info/exclude:1:z layout yields the source "info/exclude:1:z/.gitignore" and the .gitignore:1:x layout yields ".gitignore:1:x/.gitignore", so neither is trusted.
  (e) No new cause, clause, receipt field or line-4 wording (D-07, D-14). The extra findings land in the existing "changed or untracked files" clause.
- D-36: IN-02 dispositions (GAP-IN-02).
  (a) Orphan git child after a timeout: the deferral is kept. Task.shutdown ends the Elixir task and closes the port, but a git that hangs without writing may outlive it. macOS has no portable timeout utility, and each call is bounded at 60 s. The reopen trigger is unchanged: a hung or leftover git process observed during a preflight or twin run.
  (b) Submodule configuration reached by status --ignore-submodules=none: deferred with evidence, not fixed. The only candidate that this phase and twin-05 use has no gitlink entry and no .gitmodules (checked read-only during planning at 3786de95: zero mode-160000 entries; 184-10 records the count again at the new commit), so no submodule status can run. Refusing gitlinks would need new line-4 wording, which D-07 and D-14 rule out for this round. Reopen trigger: any candidate whose HEAD has a mode-160000 entry or a .gitmodules file.
</gap_decisions>
