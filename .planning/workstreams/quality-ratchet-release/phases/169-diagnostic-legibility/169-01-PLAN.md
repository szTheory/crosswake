<objective>
Close the live PR #164 defect: make one failing scanner check's own sentence reach the maintainer,
end to end, through a stable owning check — and stop `missing` from shadowing `failing`.

Purpose: Today `scanner_ids_result/2` (`lib/crosswake/release_status.ex:823-845`) discards each
check's `detail` and emits only bare ID lists, so five call sites print five identical
uninformative errors and the sentence explaining that the release would tag and publish nothing
appears nowhere. This plan is the phase's tracer: one failing check, one path, every layer.

Output: an additive ROSTER/DONE stdout protocol with a self-checking roster on the scanner; an
order-preserving parser; a new always-emitted `release.workflow_integrity` owner check carrying
verbatim detail; a multi-line render block for it; and a new proof test file.
</objective>
