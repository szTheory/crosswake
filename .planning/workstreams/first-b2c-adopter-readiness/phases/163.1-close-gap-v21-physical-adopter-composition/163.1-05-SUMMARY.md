# Phase 163.1 Plan 05: Mount the authorized study leaf inside the delivered shell Summary

The physical proof lane now mounts the existing UIKit navigation shell over a host-authorized, current-run topology while retaining the host study leaf by stack-entry identity.

## What Changed

- Linked the local `CrosswakeShellCore` Swift package into `CrosswakeProofLane` and compiled the delivered `NavigationShellViewController` with the target.
- Replaced the physical standalone branch with `NavigationShellView`, guarded by manifest/topology validation and a host-owned current-activation resolver.
- Kept invalid, stale, manifest-mismatched, and unknown-route configurations fail-closed before coordinator or leaf creation.
- Added focused unit and UI contracts that verify the physical learner hierarchy uses the shell without exposing proof-lane UI.
