## Trust Boundaries

| Boundary | Description |
|---|---|
| browser -> Phoenix endpoint | Untrusted scoped envelopes cannot establish session, scope, route, or feature authority. |
| host/Sigra callbacks -> domain mutation | Every allow decision must be current, ordered, closed, and fail closed. |
| transaction result -> retry | Lost responses and duplicates must not repeat the domain effect. |

| V3 Session Management | Compare current host-mapped scope and reject observed logout/scope change. | Tasks 1-2 | Scoped tracer and Nth-event transition cases. |
| V4 Access Control | Resolve route, gated_by, Sigra, and host authorization in locked order. | Tasks 1-2 | Complete tracer and denial-order suite. |
