<threat_model>
## Trust Boundaries

| Boundary | Description |
| --- | --- |
| Phoenix config file → `Config.normalize/1` | Untrusted host values and paths enter a closed library contract. |
| desired state → host filesystem | Concurrent or interrupted writes compete with host-owned files. |
| manifest/diff → CLI output | Host-local paths and versions become operator-visible status. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
| --- | --- | --- | --- | --- | --- |
| T-159-05 | Tampering | config paths and generator destinations | high | mitigate | Closed path grammar, expansion/containment, exclusive creation, and collision/interruption tests. |
| T-159-06 | Information Disclosure | `%Config.Error{}` and Mix output | high | mitigate | Stable rule plus canonical key/path and remediation only; negative controls assert no rejected value or contents. |
| T-159-07 | Denial of Service | concurrent generator/manifest writers | medium | mitigate | Bounded exclusive writes, deterministic collision result, sibling staging, and atomic manifest promotion. |
| T-159-08 | Repudiation | `--check` desired-state verdict | medium | mitigate | Versioned provenance/manifest checks and recursive no-write snapshots make the verdict reproducible. |
| T-159-SC | Tampering | dependency supply chain | low | accept | No install task exists; implementation uses Elixir/OTP and current locked project dependencies only. |
</threat_model>
