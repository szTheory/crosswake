## Trust Boundaries

| Boundary | Description |

| host adapter → generated probe | Host facts cross into low-cardinality observable UI and tests. |
| xcodebuild result → proof outcome | Native tool execution determines whether automation may report passed. |
| verifier → developer configuration | Hermetic package setup could mutate persistent user state. |
