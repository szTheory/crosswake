## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Repository filesystem -> approved scan set | New planning or public files can bypass privacy checks if discovery is incomplete. |
| Secret environment -> scanner memory/output | Configured private terms must be compared without disclosure, persistence, or echo. |
| Scanner result -> merge-blocking CI status | A library-only result must become an enforcing pass/fail boundary. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
