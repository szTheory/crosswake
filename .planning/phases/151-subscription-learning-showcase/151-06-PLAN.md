<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mock storefront evidence -> entitlement state | Evidence can be mistaken for access authority. |
| Demo state buttons -> access UI | Local LiveView events can overclaim production commerce behavior. |
| Course/pack gates -> learner access | Gated content must fail closed unless backend projection grants access. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-151-24 | Elevation of Privilege | `LearnLoop.Entitlement` | mitigate | Use `EntitlementProjection.derived_state/1`; pending/stale/denied fail closed. |
| T-151-25 | Spoofing | mocked storefront evidence copy | mitigate | Label evidence as mocked and never as device-verified access. |
| T-151-26 | Tampering | subscription demo state events | mitigate | Events switch demo backend projection states only; no provider SDK or access persistence is introduced. |
| T-151-27 | Product Safety | course/pack gated rows | mitigate | Tests require backend projection copy and reject live provider/native billing claims. |
| T-151-SC | Tampering | package installs | accept | No package-manager install tasks exist in this plan. |
</threat_model>
