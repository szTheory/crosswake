## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser controls -> IndexedDB | User answers become local browser records before network sync. |
| IndexedDB outbox -> sync endpoint | Local mutation payload crosses into backend validation. |
| Controller/template -> browser script | Server-rendered attributes configure client sync behavior. |
