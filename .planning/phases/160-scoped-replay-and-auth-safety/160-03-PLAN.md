<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| host authority -> browser lifecycle | Untrusted/revocable activation selects access to a sensitive partition. |
| async fetch completion -> IndexedDB/UI | A stale response attempts to mutate current local state. |
| server blocked outcome -> learner UI | Closed denial becomes calm visible state without sensitive detail. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-160-01 | Spoofing | exact-scope IndexedDB access | high | mitigate | Scope+epoch required by every production query and two-partition Playwright assertions. |
| T-160-02 | Tampering/Elevation | switch-in-flight completion | high | mitigate | Fence-first epoch invalidation and callback rechecks before all storage/UI mutations. |
| T-160-06 | Denial of Service/Elevation | blocked route drain | high | mitigate | Halt-on-blocked, no hot retry, retained queue, and deterministic request-count proof. |
| T-160-04 | Information Disclosure | console/status/proof helper | high | mitigate | Stable copy only and canary-free proof-helper assertions. |
</threat_model>
