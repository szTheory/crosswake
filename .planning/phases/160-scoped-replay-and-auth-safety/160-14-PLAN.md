<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| client request -> replay router | Untrusted JSON and cookies cannot establish authenticated account authority without the host session/backend resolver. |
| Plug.Conn -> host replay authority | Only the host may translate request-bound session state into current scope, route, feature, Sigra, and domain evidence. |
| event N-1 -> event N | Authority may change between events; every layer must be resolved again before event N mutates. |
| sensitive authority -> response/log/test evidence | Denials expose a stable class only; scope, payload, identity, credential, token, flag, and exception details stay private. |

| V4 Access Control | Scope, route, feature, Sigra, and domain checks execute in fixed order immediately before each event. | Callback-order and mid-batch authority-change tests. |
