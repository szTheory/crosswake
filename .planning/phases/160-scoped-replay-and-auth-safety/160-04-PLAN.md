<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| HTTP request -> host session/scope | Untrusted envelope cannot establish backend authority. |
| route/feature/Sigra callbacks -> mutation | Dynamic host decisions must be current and fail closed. |
| transaction response -> retry | Lost response and duplicate input must not repeat effects. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-160-01 | Spoofing/Elevation | host scope mapping | high | mitigate | Per-event conn/session resolution and exact host scope comparison before mutation. |
| T-160-03 | Elevation | authorization/feature/Sigra chain | high | mitigate | Locked ordered pipeline, deny-on-exception/timeout/malformed, and Nth-event tests. |
| T-160-05 | Tampering/Repudiation | idempotency and domain effect | high | mitigate | One Ecto.Multi transaction plus rollback/lost-response/duplicate regressions. |
| T-160-06 | Elevation | feature-disablement drain | high | mitigate | Entry and per-event gated_by checks with halt-before-next-effect assertions. |
| T-160-04 | Information Disclosure | controller errors | high | mitigate | Closed response serializers and non-echo canary tests. |
</threat_model>
