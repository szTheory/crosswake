## Visual Hierarchy

1. **Focal Point:** The step-up challenge UI element (e.g., security prompt or TOTP input) should be visually prioritized using the Secondary (#F8FAFC) background card and surrounded by xl (32px) or 2xl (48px) whitespace.
2. **Primary Action:** The "Verify Admin Identity" button uses the Accent color (#2563EB) to stand out clearly against the empty states.
3. **Typography:** The "Admin Access Restricted" heading uses Display (28px) at 600 weight to immediately convey the blocked state, while the supporting body uses 16px at 400 weight.
