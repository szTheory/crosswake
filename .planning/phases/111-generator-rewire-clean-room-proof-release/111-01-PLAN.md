<objective>
Rewire `mix crosswake.gen.shell` so its default (non-`--local`) output references the published native dep coordinates, with the version derived at generate-time from a single source of truth (`Application.spec(:crosswake)[:vsn]`).

Purpose: Today the default generator emits broken coordinates — iOS `github.com/crosswake/...` (404), Android `dev.crosswake:shell-core-android:0.1.0` (does not exist), both with a hardcoded `0.1.0`. An external adopter's generated shell cannot build. This plan makes the default output reference the real published packages with the live version, eliminating the satellite-version-drift bug (LiveView Native pattern).

Output: Modified Mix task (version assign + nil-guard), two rewired EEx templates, and dual-surface test assertions catching regressions on plain `mix test`.
</objective>
