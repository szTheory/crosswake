<objective>
Wire AUTH-02 through the compile-time and runtime activation path: declare auth predicates on
routes, carry them into manifest truth, and enforce them inside `RouteGate.evaluate/4` as a
fail-closed `:step_up_required` denial with no real step-up machinery.

Purpose: This plan turns the Phase 46 contract layer into an actual route-policy security control.
The canonical path must be `Policy DSL -> Route struct -> Manifest RouteEntry -> RouteGate ->
Shell.Denial`, and it must halt closed whenever backend authority is missing or insufficient.

Output: auth predicate support in policy/schema/route/manifest code, `:step_up_required` in the
denial vocabulary, and a hermetic phase proof file covering the full path.
</objective>
