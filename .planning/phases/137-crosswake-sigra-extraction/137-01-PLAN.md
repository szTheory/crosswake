Land the CORE side of the D-4 Finding boundary refactor as the non-negotiable green baseline
BEFORE any package move. Core owns Finding→Denial translation; after this plan the
`evaluate_auth/3` behaviour contract returns `{:deny, Finding.t()}` and `RouteGate` translates
that Finding to a `Denial` at the accumulation site. This plan does NOT touch sigra internals
(that is Plan 02) — the sigra facade still passes a Denial through today, so this plan keeps
core green on its own by adding the fields/clause/translation and leaving the facade pass-through
comment updated but behaviourally unchanged until Plan 02 flips the evaluator.

D-137-B (`:auth` clause + guarded base_details merge). Adds `StubSigraAbsentCompanion` (D-137-D)
for the engine-absent fail-closed proof.

Purpose: A silent contract break if RouteGate pushed a raw Finding into a Denial list; core
must be the single owner of the translation. Landing this first means Plan 02's evaluator flip
compiles against a callback that already expects Finding.
Output: Finding struct with :code/:details, the guarded :auth translation clause, RouteGate
translation call, updated callback spec/docstring, StubSigraAbsentCompanion.
</objective>
