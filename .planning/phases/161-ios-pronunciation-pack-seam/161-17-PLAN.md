<objective>
Make the generated reference-adapter proof certify a current-run foreground installation instead of accepting stale simulator persistence.

Purpose: Close the sole Phase 161 verification blocker by proving the causal chain reset → initial Blocked → foreground install → Passed → relaunch readback → denied-network audio.
Output: A test-only reset launch contract, accessibility-driven current-run XCUITest assertions, and template/verifier regressions that reject stale or reordered provenance.
</objective>

<gap_root_cause>
The reference adapter stores its verified fixture at a stable Application Support location. `test-without-building` reuses simulator application data, while the generated UI test currently taps Install and accepts any Passed result without clearing persistence or first observing Blocked. Therefore stale bytes can satisfy install, relaunch, and audio markers even when the current invocation installs nothing.
</gap_root_cause>
