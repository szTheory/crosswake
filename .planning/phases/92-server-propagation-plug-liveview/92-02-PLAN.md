| on_mount → Logger.metadata | The id propagates into the LiveView process metadata |

## STRIDE Threat Register

| T-92L-02 | Information Disclosure / Tampering | Oversized or non-string connect-param value | mitigate | Guard `is_binary(id) and byte_size(id) > 0` rejects non-binaries and empties before setting metadata (Task 1). Value stored opaquely in `Logger.metadata`; host owns log-sink hygiene. |
| T-92L-03 | Tampering | Calling `get_connect_params` on a disconnected mount (raises / unexpected behavior) | mitigate | `connected?(socket)` guard precedes the read (Pitfall 1, Task 1). |
| T-92L-SC | Tampering | npm/pip/cargo installs | n/a | Phase 92 introduces zero new packages. |
</threat_model>
