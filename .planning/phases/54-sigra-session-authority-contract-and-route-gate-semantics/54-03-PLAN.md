## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| backend authority contract -> shared evaluator | Route activation policy consumes backend auth facts and must not treat malformed or stale data as allow. |
| shared evaluator -> RouteGate decision | Internal auth results flow into the canonical route-activation engine and must preserve ordering and denial semantics. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-54-09 | Spoofing | `Crosswake.Companions.Sigra.Evaluator` | mitigate | Deny missing or invalid auth context explicitly and consume only validated `AuthContext` / `SessionAuthorityLane` instances. |
| T-54-10 | Elevation of Privilege | remembered/cached posture handling | mitigate | Enforce explicit `auth_posture`, block remembered/cached auth on strict or recent-auth routes, and emit dedicated canonical denial codes per D-17. |
| T-54-11 | Tampering | `RouteGate` precedence chain | mitigate | Preserve kill-switch and companion-gate precedence before auth, and keep auth before compatibility/commerce so no later layer can override a denial per D-11. |
| T-54-12 | Information Disclosure | denial envelope production | mitigate | Reuse the canonical sanitizer so evaluator facts never leak tokens, provider payloads, credential ids, or raw session references. |
</threat_model>
