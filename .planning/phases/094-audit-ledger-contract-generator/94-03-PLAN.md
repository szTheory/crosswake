<objective>
Implement the idempotent Mix generator `crosswake.gen.audit`.

Purpose: Provide a simple command for hosts to pull the standard Audit Ledger templates into their own application context.
Output: `Mix.Tasks.Crosswake.Gen.Audit` mix task and comprehensive unit tests.
</objective>

<feature>
  <name>Audit Ledger Mix Generator</name>
  <files>lib/mix/tasks/crosswake.gen.audit.ex, test/mix/tasks/crosswake.gen.audit_test.exs</files>
  <behavior>
    - `Mix.Tasks.Crosswake.Gen.Audit.run/1` accepts optional `--app` and `--dir` flags.
    - It derives the host's app name and evaluates `priv/templates/crosswake/audit/ledger.ex.eex` to create `lib/my_app/audit/ledger.ex`.
    - It checks if `lib/my_app/audit/ledger.ex` exists. If so, it skips writing and prints `[crosswake] reused ...`. If not, it writes it and prints `[crosswake] created ...`.
    - It evaluates `priv/templates/crosswake/audit/migration.exs.eex`.
    - It checks the host's `priv/repo/migrations/` directory for any file matching `*create_crosswake_audit_events.exs`. If one exists, it skips writing the migration and prints `[crosswake] reused ...`.
    - If no migration exists, it generates a timestamped filename (e.g. `YYYYMMDDHHMMSS_create_crosswake_audit_events.exs`), writes the evaluated template there, and prints `[crosswake] created ...`.
  </behavior>
  <implementation>
    Implement `Mix.Tasks.Crosswake.Gen.Audit` modeled closely on `Mix.Tasks.Crosswake.Gen.Sync`.
    Ensure `ensure_file/2` style idempotency is used.
    For the migration check, explicitly list files in `priv/repo/migrations` to detect the suffix, and only generate if missing.
  </implementation>
</feature>
