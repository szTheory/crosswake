<objective>
Implement the core Audit Ledger contract struct and HMAC anonymization helper.

Purpose: Provide the canonical event shape for downstream producers and a standard way to anonymize actor IDs before they reach the generated Ecto schema.
Output: `Crosswake.Audit.Ledger` module with a `defstruct` and `actor_ref/2` function.
</objective>

<feature>
  <name>Audit Ledger Contract and HMAC Helper</name>
  <files>lib/crosswake/audit/ledger.ex, test/crosswake/audit/ledger_test.exs</files>
  <behavior>
    - `Crosswake.Audit.Ledger` defines a `@type t :: %__MODULE__{}` and a `defstruct` with all canonical keys initialized to `nil`: `thread_id`, `correlation_id`, `route_id`, `actor_ref`, `actor_kind`, `event_class`, `event_type`, `outcome`, `provenance`, `occurred_at`, `recorded_at`, `idempotency_key`, `metadata`, `row_hash`, `prev_hash`.
    - `Crosswake.Audit.Ledger.actor_ref/2` accepts an `id` and an optional `opts` keyword list (default `[]`).
    - If `opts[:secret]` is provided, it computes the HMAC-SHA256 of `to_string(id)`.
    - If `opts[:secret]` is not provided, it falls back to `Application.get_env(:crosswake, :audit_hmac_secret)`.
    - If no secret is found, it raises an ArgumentError.
    - The computed HMAC is returned as a lowercase base16 string (`Base.encode16(case: :lower)`).
  </behavior>
  <implementation>
    Define the `Crosswake.Audit.Ledger` module.
    Add the `defstruct` with all 15 required keys.
    Implement `actor_ref/2` using Erlang's `:crypto.mac(:hmac, :sha256, secret, to_string(id))`.
  </implementation>
</feature>
