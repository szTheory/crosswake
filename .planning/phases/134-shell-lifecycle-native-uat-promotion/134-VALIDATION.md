### Drift-Catch Validation (positive AND negative)

1. **Negative (must FAIL when templates change):** mutate one `.eex` byte → drift test MUST fail at `:merge_blocking` → reset. Manual dev-time check; document in bump ceremony.
2. **Positive (must PASS after bump):** `mix crosswake.bump_template_version` → drift test MUST pass. Normal bump flow.
3. **Non-vacuity (must FAIL if a platform's templates removed):** delete all iOS templates → non-vacuity guard MUST fail.
