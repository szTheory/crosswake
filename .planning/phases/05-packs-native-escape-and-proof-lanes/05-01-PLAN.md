<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Phoenix route DSL -> manifest pack registry | Ambiguous pack declarations here would create unsafe or dishonest shell behavior later |
| manifest pack registry -> native shell consumers | If shells are allowed to reinterpret pack metadata, Crosswake loses route-policy-first ownership |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | T | `lib/crosswake/policy/schema.ex` | mitigate | Reject duplicate, underspecified, or runtime-inconsistent pack declarations at compile time |
| T-05-02 | T | `lib/crosswake/manifest/builder.ex` | mitigate | Compile pack registry entries only from normalized route truth and keep routes referencing immutable ids and versions |
| T-05-03 | R | manifest pack contract | mitigate | Validate that every route reference resolves through the registry so doctor/docs/proof can assert one canonical source of truth |
</threat_model>
