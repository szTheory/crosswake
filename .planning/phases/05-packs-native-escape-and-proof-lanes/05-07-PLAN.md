<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| bridge command -> shell transfer executor | Overbroad dispatch would widen Crosswake into a generic file subsystem |
| native capture result -> transfer coordinator | Implicit upload here would hide the distinction between local staging and transfer |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-19 | E | iOS and Android bridge channel templates | mitigate | Dispatch only manifest-allowed `transfer.*` commands and reject undeclared commands fail-closed |
| T-05-20 | T | `TransferCoordinator` templates | mitigate | Keep transfer state foreground-first and require explicit staged-file handoff before upload or export proceeds |
| T-05-21 | I | generated WebView surfaces | mitigate | Do not rely on generic file chooser or download callbacks as the primary transfer path |
</threat_model>
