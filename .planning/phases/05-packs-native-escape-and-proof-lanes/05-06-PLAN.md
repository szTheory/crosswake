<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| route activation -> native capture screen | If activation falls back incorrectly, Crosswake would hide runtime ownership truth |
| local captured file -> transfer handoff | Untyped or implicit handoff would blur the line between local capture and host transfer |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-16 | E | generated shell activation templates | mitigate | Open the capture surface only for manifest-declared `:native_screen` routes and deny all fallback container behavior |
| T-05-17 | T | `lib/crosswake/native_escape/runtime.ex` | mitigate | Return typed local capture metadata and require explicit transfer handoff before upload or download state can advance |
| T-05-18 | I | native capture UI | mitigate | Keep visible ownership labels and denial copy so users can distinguish native capture from LiveView or WebView flows |
</threat_model>
