## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| migration guide -> adopter implementation choices | Readers may move route authority based on migration advice. |
| migration guide -> bridge/offline/native claims | Promotion criteria can overclaim bridge, offline, or native evidence if not explicit. |
| docs -> native evidence labels | Local native host walkthroughs can be mistaken for generated public-coordinate proof. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-117-02 | Spoofing / Repudiation | migration owner decisions | mitigate | Default to LiveView and require explicit promotion reasons from D-08. |
| T-117-03 | Tampering | offline migration advice | mitigate | Require cached read-only vs true local mutation/replay distinction and reject cached LiveView mutation claims. |
| T-117-04 | Elevation of Privilege | backend/provider and bridge advice | mitigate | Reject high-frequency bridge authority and device/provider authority without backend reconciliation. |
| T-117-SC | Tampering | package installs | accept | No npm, pip, or cargo package installs are planned. |
</threat_model>
