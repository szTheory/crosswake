<objective>
Close the OPER-01 gap in `mix crosswake.threadline`. The task uses `Enum.sort_by/2` without a comparator (line 96), which applies Erlang structural term order to NaiveDateTime/DateTime structs. Erlang compares struct map keys alphabetically (`:day` before `:month` before `:year`), so events spanning a month or year boundary sort incorrectly. The tool's stated purpose is chronological sequence reconstruction; this defect makes the output wrong for any real multi-month audit window.

Purpose: Make the operator timeline trustworthy for real-world audit windows that cross month/year boundaries.

Output: Corrected `lib/mix/tasks/crosswake.threadline.ex` (date-comparator sort) and a regression test in `test/mix/tasks/crosswake.threadline_test.exs` with out-of-order events spanning a month boundary.
</objective>
