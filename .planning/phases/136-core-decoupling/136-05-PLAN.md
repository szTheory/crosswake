<objective>
Extend the `companion_guard.ex` AST guard so it (a) matches banned aliases by prefix containment
instead of exact list equality (child modules currently pass silently), (b) adds `Sigra` and
`Chimeway` to the banned set, and (c) scopes the walk to all of `lib/**/*.ex` MINUS
`lib/crosswake/companions/**/*.ex`; then invert the Phase-130 non-vacuity assertion and add a
scope-exclusion test.

Purpose: DECOUPLE-06. The guard must cover all core `lib/` files (not just the companion dir)
and fail the build on any new static core->companion reference — the boundary enforcement that
lets core compile with no companion present. This plan runs LAST: it bans Sigra/Chimeway
aliases, so all core inversion sites (Plans 02/03/04) must already have removed those aliases or
`assert_no_static_refs!` would flag them.

Output: A prefix-matching, correctly-scoped guard with Sigra+Chimeway banned, and a Phase-130
test that proves the child-module detection (non-vacuity) and the in-tree scope exclusion.
</objective>
