<objective>
Convert the two stale-beam module attributes in `support_matrix.ex`
(`@auth_contract_truth`, `@notification_support_truth`) into `def` runtime helpers and replace
the `Sigra.DenialCodes` fallback defaults in `doctor.ex` with runtime registry lookups — so no
companion function is called at module-evaluation time and no static Sigra reference remains.

Purpose: DECOUPLE-03. Module attributes computing companion values at compile time bake stale
data into the `.beam` (stale-beam footgun); they must become runtime helpers reading the
`:companions` registry via the `denial_codes/0` callback. Doctor's `Map.get/3` default
expressions eagerly call `Sigra.DenialCodes` even when the key exists — those must move to
runtime registry lookups.

Output: A `support_matrix.ex` with runtime `auth_contract_truth/0` / `notification_support_truth/0`
and no Sigra alias, and a `doctor.ex` with no static `Sigra.DenialCodes` reference.
</objective>
