<objective>
Invert the two `telemetry.ex` compile-time coupling sites onto the runtime `:companions`
registry, add the 10-atom core PII baseline denylist, and cache the merged forbidden-key MapSet
once in `attach_default_logger/1` (captured in the handler closure) rather than re-aggregating
per event.

Purpose: DECOUPLE-01 and DECOUPLE-05. Core telemetry must aggregate companion events and
forbidden keys with no compile-time Sigra/Chimeway reference, and must always apply a hardcoded
PII floor even when no companion is present — an absent/misconfigured companion can never
silently drop token/identity scrubbing.

Output: A telemetry module with zero static companion references, a public
`baseline_forbidden_metadata_keys/0`, an attach-time-cached forbidden set, and a Phase-133 test
that no longer hardcodes the 24 companion event count.
</objective>
