<objective>
Invert the `route_gate.ex` auth-evaluation coupling: remove the static
`Crosswake.Companions.Sigra.Evaluator` alias, inline the auth-predicate detection, and dispatch
auth evaluation through the `:companions` registry via `auth_authority?/0` + `evaluate_auth/3`
with a fail-closed no-companion guard and a rescue wrapper.

Purpose: DECOUPLE-02 and DECOUPLE-04. Core owns the fail-closed contract; auth-predicated routes
must deny with `:dependency_missing` when no auth authority is registered, and a companion that
raises during evaluation must be rescued and also deny — never fail open. The `Finding`-boundary
refactor is explicitly OUT of scope (Phase 137); `evaluate_auth/3` returns `Denial.t()` and core
passes it through directly (zero type-translation).

Output: A `route_gate.ex` with no static Sigra reference, an inlined predicate check, registry
auth dispatch, and the fail-closed + rescue guards the backstop tests assert.
</objective>
