## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions runner → Maven Central Portal | The fire-drill uploads signed artifacts using ORG_GRADLE_PROJECT_* secrets; a leaked log line or auto-publish burns a coordinate |
| GitHub Actions runner → mirror repo (szTheory/crosswake-shell-core-ios) | MIRROR_PUSH_TOKEN pushes a split tree + tag; a force-push or over-scoped token is a tampering/EoP risk |
| third-party action / splitsh-lite binary → CI execution | Supply-chain: an un-pinned action or tampered tag (CVE-2025-30066 class) executes with secret access |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
