# Plan 59-02: Chimeway Redaction Boundary And Telemetry Sanitizer

<objective>
Turn raw bridge/provider inputs into safe Chimeway evidence and telemetry surfaces without introducing any public raw-token field, provider payload leak, or premature delivery claim.
</objective>

<context>
This plan depends on the contract modules from `59-01`. Keep raw token handling at the boundary only. Do not add provider credentials, topic APIs, delivery adapters, Ecto schemas, or notification-open routing.

<interfaces>
From `lib/crosswake/bridge/commands/notification_token.ex`:

```elixir
@spec new_response(keyword()) :: Response.t()
def new_response(attrs) when is_list(attrs)
```

From `lib/crosswake/companions/sigra/telemetry.ex`:

```elixir
@spec event_names() :: [[atom()]]
@spec metadata_keys() :: [atom()]
@spec forbidden_metadata_keys() :: [atom()]
@spec metadata(Event.t() | map() | keyword()) :: map()
@spec to_map(Event.t()) :: map()
@spec execute([atom()], map(), map() | keyword()) :: :ok
```
</interfaces>
</context>
