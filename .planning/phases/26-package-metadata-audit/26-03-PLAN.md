## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| docs/0 :extras list → hexdocs.pm rendered pages | The extras list determines what content adopters see as navigable pages on `https://hexdocs.pm/crosswake/0.1.0/`. A missing entry silently omits documentation; an entry referring to a non-existent file (forward-reference) breaks `mix docs`. |
| ex_doc dev dep → adopter transitive deps | Without `only: :dev, runtime: false`, ex_doc would become a transitive compile dep for every adopter — bloating their build (Pitfall 8 secondary risk). |

Extras references `README.md`, `LICENSE`, and `guides/*.md`. `:files` (plan 02) contains `README.md`, `LICENSE`, and `guides` directory. Cross-check is satisfied. |
