<objective>
Ship the structural gate that makes FALL-02 a rule rather than a convention:
`Crosswake.ComponentTierGuard`, resident in `lib/`, enforcing six rules over `lib/**/*.ex` —
five that assert nothing UI-shaped ships importable, and one anti-vacuity twin that asserts
the components DO exist, as adopter-owned template text.

a project that ships nothing. The actual requirement is "components exist only as adopter-owned
text", and a guard that cannot tell those two claims apart is theater.

Purpose: deleting a test must not delete a rule, and the rule must be able to fail. Both are
proven here — the guard lives in `lib/`, and four separate controls prove the rules have teeth.
Output: one `lib/`-resident guard with a fixture injection seam, one untagged repo-root test
carrying a multi-violation set assertion plus five one-rule synthetics plus a positive control
plus an attestation, and a failure message that teaches retirement instead of suppression.
