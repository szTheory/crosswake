<objective>
Complete the token work the tracer started and close the gate hole that let a failing focus
ring ship green.

Three moves, all measured rather than asserted: add `--cw-status-error-fg` so a destructive
button keeps a colour channel on dark; correct `--cw-action-focus-ring`'s light value from
brass-500 (2.93:1 on white — below WCAG SC 1.4.11's 3:1 floor, already shipped and live) to
wake-700; and widen `contrast.test.mjs` with a non-text UI-component assertion class so this
entire class of failure can never ship silently again.

Purpose: success criterion 2 requires the fallbacks "meet the existing contrast gates".
Shipping a ring that fails 1.4.11 through a gate that cannot see it would satisfy the letter
and violate the point. This plan makes the gate able to see it.
Output: two corrected/added tokens, a new assertion class in the contrast suite, a mechanical
token-count cap, and a group-exhaustiveness assertion that kills the silent-drop class of bug.
</objective>
