## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| route activation → companion gate evaluation | RouteGate dispatches to the rulestead companion; a wrong return value could fail-open and grant a gated route |
| host config → companion enablement | `Application.get_env(:crosswake, :rulestead)` drives `enabled?/1`; a permissive default would enable a companion whose dependency is missing |
| test process → MockFlagSource Agent | shared named process whose state leaking across tests could produce false-positive proofs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-42-01 | Elevation of Privilege | `Crosswake.Companions.Rulestead.enabled?/1` | mitigate | Default `Map.get(config, :enabled, false)` — fail-closed; companion only dispatched when host explicitly enables it (asserted by SC#3b clean case) |
| T-42-03 | Denial of Service / fail-open | `kill_switch_active?/1` returning nil | mitigate | Callback returns strict boolean; nil-guarded `Process.whereis` returns `false` when source down (never nil); :killed scan returns `true`/`false` only |
| T-42-04 | Tampering (test reliability) | MockFlagSource shared Agent state across proof runs | mitigate | `start_supervised!/1` in setup gives a fresh Agent per test via ExUnit teardown; `reset/0` available as belt-and-suspenders |
| T-42-05 | Tampering | `validate_dependency/0` swallowing errors | mitigate | Returns typed `:ok | {:error, [module()]}` via `Code.ensure_loaded?/1`; no rescue/catch-all that hides a missing dependency |
| T-42-SC | Tampering | npm/pip/cargo installs | accept | No package-manager installs in this phase — zero new dependencies (RESEARCH Package Legitimacy Audit: not applicable) |
