<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PR author → merge gate | a PR carrying hand-edited generated surfaces or a manifest drift crosses into main here |
| maintainer shell → branch protection API | the registration script mutates required_status_checks via an admin-scoped gh PATCH |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-122-07 | Tampering | a newly-emitted untracked generated file passing a bare `git diff --exit-code` | mitigate | gate stages with git add -A then git diff --cached --exit-code so untracked output is caught |
| T-122-08 | Elevation of privilege | register-contract-gate.sh widening branch protection beyond the one aggregator or hardening the full protection PUT | mitigate | granular required_status_checks endpoint only, reads live strict + unique_by(.context); enforce_admins/reviews untouched; maintainer-run, documented, not auto-toggled |
| T-122-09 | Denial of service | registering a never-seen required check freezes all PRs with "Expected — Waiting for status" | mitigate | green-first preflight refuses (exit 2) until the aggregator has gone green on main at least once |
| T-122-10 | Repudiation | a non-hermetic gate job that flakes on native toolchain absence, eroding the merge signal | mitigate | both sibling jobs are pure-Elixir/hermetic (no Xcode/Gradle), pinned to .tool-versions; native checks stay advisory |
</threat_model>
