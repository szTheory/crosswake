<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client Browser -> IndexedDB | Untrusted client-side execution environment writing to local storage. Any data in IndexedDB can be tampered with by the user. |
| Offline Client -> Server Sync | Future sync of the mutation queue to the server crosses a major trust boundary. The server must eventually validate all queued actions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-88-01 | Tampering | offline_study.js / IndexedDB | accept | Data in IndexedDB is inherently tampered-able by the client. We accept this local risk but must enforce validation during the server sync phase (later). |
| T-88-02 | Spoofing | IndexedDB Mutation Queue | mitigate | Ensure queued events record timestamps and basic schema validation locally to avoid JS errors, though full authorization check will be on server. |
</threat_model>
