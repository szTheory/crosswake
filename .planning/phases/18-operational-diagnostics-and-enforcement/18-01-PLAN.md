<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Phoenix route DSL -> manifest/validator | Untrusted developer input must be normalized to the supported family vocabulary before becoming runtime truth. |
| LiveView route -> bridge registry | Runtime requests can carry any command string and must be checked against the active route plus transfer seams. |
| Bridge payload -> transfer seam lookup | `transfer_id` is untrusted until matched to a route-local inbound `native_picker` declaration. |

| T-18-03 | Spoofing | active route command dispatch | mitigate | Preserve inactive-route and unsupported-command denials, and keep `deep_link` out of the bridge allowlist per D-04 and D-08. |
</threat_model>
