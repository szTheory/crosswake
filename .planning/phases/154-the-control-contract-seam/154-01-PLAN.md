<objective>
Flip the *published* capability vocabulary from the dotted command form to the family form
(`haptics.impact` → `haptics`) everywhere Crosswake teaches route policy, fix the
self-referential `legacy_ids` bug that makes the shipped manifest carry a duplicate haptics
entry, and add the doctor advisory that is the only honest deprecation surface available.

This is D-76's **PR #1**: no behavior change, deliberately landed before the seam so that if
a merge-blocking gate goes red there is a clean bisect point. The hand-rolled `<script>` IIFE
is deliberately untouched here — it moves in PR #3 (Plan 07), so the Playwright payload helper
is not rewritten while the vocabulary is moving.

Purpose: CTRL-03's error message must name the *family* the adopter forgot to declare (D-62 —
route policy declares families, the bridge dispatches commands). Teaching the dotted form and
then raising about the family form would be incoherent, so the vocabulary lands first.

Output: family-form route policy in the reference host, a single correct haptics manifest
entry, a doctor advisory, and three guides that teach the distinction.
</objective>
