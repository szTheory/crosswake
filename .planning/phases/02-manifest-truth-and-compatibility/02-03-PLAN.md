## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Install/compiler/manifest truths -> doctor report | Doctor can become dishonest if it scrapes or reformats inconsistently from canonical sources |
| Doctor JSON output -> CI/tooling consumers | Unstable schemas can break downstream verification or hide failures |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-11 | T | `lib/crosswake/doctor/json_formatter.ex` | mitigate | Emit JSON from structured finding structs and canonical contract modules rather than reparsing terminal output |
| T-02-12 | R | `lib/crosswake/doctor/doctor.ex` | mitigate | Preserve finding codes, severities, and check names so CI and operators can prove which blocking truth failed |
| T-02-13 | I | doctor terminal/JSON output | mitigate | Keep findings limited to setup, compatibility, route-policy, and support truth; do not dump secrets or opaque environment state |
| T-02-14 | D | `lib/mix/tasks/crosswake.doctor.ex` | mitigate | Separate blocking `error` findings from `warning` and `advisory` so unsupported host truth stops the task instead of being buried in noise |
</threat_model>
