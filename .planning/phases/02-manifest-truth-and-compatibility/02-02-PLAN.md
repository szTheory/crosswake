<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Router metadata/compiler output -> manifest artifact | Invalid mapping or omission can cause manifest drift from authoritative route truth |
| Typed manifest -> serialized JSON | Serialization bugs can tamper with compatibility/support claims or route ownership semantics |
| Manifest validation -> downstream artifact consumers | Weak validation can let dishonest or unsafe contract data ship |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | T | `lib/crosswake/manifest/builder.ex` | mitigate | Build route entries directly from normalized `%Crosswake.Policy.Route{}` values so manifest routes cannot drift from authoritative router-local policy |
| T-02-06a | T | `lib/crosswake/manifest/validator.ex` | mitigate | Centralize manifest-schema, compatibility, and support-matrix validation before serialization so partial or inconsistent manifest truth cannot reach disk |
| T-02-07 | T | `lib/crosswake/manifest/serializer.ex` | mitigate | Use deterministic serialization and idempotent writes to prevent accidental JSON shape drift across runs |
| T-02-08 | R | `lib/crosswake/manifest/manifest.ex` | mitigate | Return structured validation failures instead of opaque strings so CI and doctor surfaces can prove why output was blocked |
| T-02-09 | D | manifest generation path | mitigate | Fail artifact generation early on missing compatibility/support sections rather than producing partial JSON that later consumers might misread |
| T-02-10 | E | route activation contract | mitigate | Preserve route-first ownership, compatibility truth, and capability registry truth in the artifact so later shells cannot silently activate unsupported routes |
| T-02-10a | T | remote manifest update semantics | mitigate | Reject unversioned overlays, rule-order semantics, and patch-style rewrites in `lib/crosswake/manifest/validator.ex`; permit only versioned manifest replacement or typed companion data per D-07 |
</threat_model>
