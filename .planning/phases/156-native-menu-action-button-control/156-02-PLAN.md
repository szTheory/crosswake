<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Route policy -> runtime projection | Static authorization constrains localized per-record menu data. |
| LiveView -> browser hook | Structured payload and explicit DOM anchor cross into client-controlled state. |
| Browser hook -> native transport | Capability/version and geometry facts gate native dispatch. |
| Native reply -> LiveView | A selected action id is untrusted input, never mutation authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-156-01 | Elevation of Privilege | action projection validator | high | mitigate | Enforce policy subset, exact destructive classification, nil icons, uniqueness, and reply membership before dispatch/delivery. |
| T-156-02 | Tampering | anchor metadata and shell facts | high | mitigate | Derive geometry in the hook, reject invalid rectangles, and preflight injected compatible capability facts before post. |
| T-156-03 | Spoofing | native selected action id | high | mitigate | Bind selectable ids to the in-flight projection and reject unknown/disabled ids before adopter code. |
| T-156-04 | Denial of Service | action count and labels | medium | mitigate | Enforce eight rows and 80 Unicode graphemes before dispatch. |
| T-156-05 | Information Disclosure | bridge telemetry | medium | mitigate | Do not emit labels, ids, DOM ids, coordinates, record ids, or refs. |
</threat_model>
