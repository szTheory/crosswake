<objective>
Create `CrosswakeExample.Commerce.MockStorefront` — a pure-Elixir, provider-neutral evidence emitter in the example host. It has exactly two public functions:

- `simulate_purchase/2` consumes a `Crosswake.Commerce.Contracts.PurchaseIntent` and returns a `%ReconciliationEvidence{source: :storefront, provider: "mock", event_kind: "purchase"}` whose `provider_reference`/`evidence_ref` are deterministic functions of `intent.entry_id` (never `correlation_id`).
- `simulate_restore/2` consumes a `Crosswake.Commerce.Contracts.RestoreIntent` and returns a `%ReconciliationEvidence{source: :storefront, provider: "mock", event_kind: "restore"}` anchored on the canonical `@subscription_entry_id` module constant.

Both return the RAW struct (no `{:ok, _}` wrapper) and take an optional `captured_at` clock seam. The `@moduledoc` documents the module as a drop-in swap target.

Purpose: This module manufactures the stable provider identity that the existing Phase 21 `ReconciliationKeys`/`ReconciliationInbox` machinery needs to prove the idempotency invariant in Plan 02. It models "a real storefront transaction id dedupes network retries" without any provider SDK.

Output: One new file — `examples/phoenix_host/lib/crosswake_example/commerce/mock_storefront.ex`.
</objective>
