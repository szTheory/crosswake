## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Phoenix route author -> route policy schema | Developer-authored route metadata enters the compile pipeline and must be constrained to explicit enums and shapes |
| Raw metadata -> normalized structs | Untyped option maps cross into code that later phases will trust for manifest generation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | T | `lib/crosswake/policy/schema.ex` | mitigate | Deny unknown keys and invalid enum values with `NimbleOptions`, especially runtime values outside the D-05 taxonomy |
| T-01-02 | E | `lib/crosswake/policy/route.ex` | mitigate | Require explicit `id` and `runtime` per D-09 so later phases cannot infer privileged behavior from partial declarations |
| T-01-03 | R | tests and normalized structs | accept | Phase 1 is compile-time substrate only; authorship attribution beyond file/line diagnostics is deferred until later tooling phases |
</threat_model>
