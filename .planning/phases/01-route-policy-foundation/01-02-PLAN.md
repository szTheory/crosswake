<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Router DSL -> Phoenix route compilation | Route authors inject Crosswake metadata into router declarations that become trusted compile-time inputs |
| Scope defaults -> route overrides | Shared defaults can accidentally over-broaden route privileges if merge order is wrong |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04 | T | `lib/crosswake/policy/merge.ex` | mitigate | Apply deterministic merge order where route-local declarations win over scope defaults, preventing silent privilege expansion |
| T-01-05 | I | `lib/crosswake/policy/router_metadata.ex` | mitigate | Store compiled policy on explicit metadata keys without mutating unrelated Phoenix route metadata |
| T-01-06 | E | `lib/crosswake/router.ex` | mitigate | Keep Crosswake authoring restricted to router-adjacent metadata per D-01/D-02 so no parallel registry can bypass validation paths |
</threat_model>
