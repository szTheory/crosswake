<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Crosswake installer -> host Phoenix app files | Automated code generation edits user-owned files and must remain explicit, reviewable, and idempotent |
| Crosswake shell generator -> native workspace skeletons | Generated native files may be mistaken as library-owned unless ownership is documented clearly |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-10 | T | `lib/crosswake/install/patcher.ex` | mitigate | Use explicit patch markers plus idempotent detection to prevent repeated installer runs from corrupting router or config files |
| T-01-11 | R | install manifest and docs | mitigate | Persist scaffold state and document generated artifacts so hosts can audit what Crosswake changed and owns |
| T-01-12 | E | shell generator outputs | mitigate | State clearly in generated docs and CLI output that native skeletons are host-owned and not privileged Crosswake runtime surfaces |
</threat_model>
