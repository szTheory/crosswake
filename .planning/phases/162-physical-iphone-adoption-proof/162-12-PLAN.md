## Trust Boundaries

| Boundary | Description |
|---|---|
| learner text field -> host journal | Sensitive free-form content crosses from UI memory into durable local storage and must retain exact value semantics. |
| active opaque scope -> journal partition | One scope may read/write only its own partition; scope changes cannot inherit prior values. |
| host session provider -> device scope selection | Only validated host launch/session state may select a partition; missing/logout/account-switch state fences before reads or replay. |
| device outbox -> Phoenix `/study/sync` | Sensitive mutation content crosses to existing request-bound backend authority and must drain only after accepted exactly-once proof. |
| journal readback -> XCUITest assertion | Raw value/integrity material stays process-local while only a closed pass/fail observation crosses to test output. |
| XCTest output -> retained evidence/support truth | Reports and evidence may carry fixed assertion IDs/outcomes only. |
