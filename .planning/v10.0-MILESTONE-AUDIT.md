## Tech Debt Summary

**Drift-gate detection-edge gaps (Phase 109, documented as WR-01..WR-05):** the gate reliably fails on bare brand hex / lost token reference in the *current* manifest files, but has known future false-negatives — SVG attribute hex (`fill="#..."`), 4-/7-digit hex shorthands, and dynamic `class={...}` bindings. No current manifest file triggers any of these. These must be closed before adding a new consumer type (SVG-in-HEEX or dynamic class bindings) to the manifest.

**Manual vendor re-copy:** the example host's `tokens.css` is a vendored copy requiring an explicit re-vendor step after a source token change (intentional, documented). The package's own `priv/static/crosswake/tokens.css` IS auto-synced and gated.

**Nyquist validation incomplete** across all three phases (see table above).
