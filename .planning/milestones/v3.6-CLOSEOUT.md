# v3.6 Closeout Contract: Operator Truth and Production Diagnostics

This is the live closeout ledger for v3.6. It is not the milestone audit. The
audit remains append-only evidence; this file is the checklist and machine-readable
contract that must be true before the milestone is considered closed.

## Contract Posture

Closeout follows the same planning-contract posture recorded in
`.planning/MILESTONE-ARC.md`: required fields are explicit, composable across
artifacts, boringly named, and fail closed when required evidence is absent. A
missing artifact is either fixed or recorded as `deferred_with_reason`; it is
never silently accepted.

## Exception Shape

Use this exact `deferred_with_reason` shape when a required closeout item is
intentionally not final at close:

```yaml
deferred_with_reason:
  - owner: maintainer
    scope: validation-ledger-finalization
    reason: "Why this can safely remain open without changing shipped support truth."
    revisit_phase: 53
    evidence: ".planning/phases/NN-*/NN-VERIFICATION.md"
    status: open
```

Freeform exception prose is not enough. Every exception needs `owner`, `scope`,
`reason`, `revisit_phase`, `evidence`, and `status`.

## Phase 53 Enforcement Target

Phase 53 must promote this contract into a merge-blocking `closeout.verify`
check or an equivalent deterministic wrapper. The check must fail closed on:

- missing or stale roadmap parity
- missing, unchecked, or unarchived requirements state
- stale `.planning/STATE.md` milestone/frontmatter status
- missing phase verification evidence
- malformed or missing SUMMARY frontmatter
- validation-ledger drift without `deferred_with_reason`
- unresolved thread/seed status without owner and next routing
- public support-claim changes without release/changelog continuity
- malformed `deferred_with_reason` exceptions missing `owner`, `scope`,
  `reason`, `revisit_phase`, `evidence`, or `status`
- missing `.planning/MILESTONE-ARC.md` strategic queue refresh after public
  support scope changes

Human judgment remains appropriate for the wording of durable lessons and
release positioning. Artifact existence, traceability, and exception shape are
deterministic parity truth and must be checked mechanically.
