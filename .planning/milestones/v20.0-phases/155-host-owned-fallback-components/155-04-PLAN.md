<objective>
Make `tokens.css` have exactly one served source of truth, and make the installer able to
deliver a changed canonical block to adopters who already ran it.

Three shipped defects close here. The reference host carries a third, byte-identical,
completely ungated `tokens.css` copy that will now silently go stale every time a token is
added. `mix crosswake.gen.offline_ui` emits a root layout linking `~p"/assets/tokens.css"`, a
URL no endpoint serves — a live 404. And `Crosswake.Install.Patcher` treats "the markers exist"
as sufficient, so the widened `only:` list from 155-01 will never reach a Phase 154 adopter.

Purpose: 155-01 proved the served path works for the one route the tracer touches. This plan
generalizes it and removes the copies that would drift behind it.
Output: one served `tokens.css`, a reconciling installer, and two honest doctor findings.
</objective>
