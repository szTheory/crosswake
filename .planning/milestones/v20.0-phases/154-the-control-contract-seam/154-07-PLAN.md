<objective>
Prove the seam against an already-native, zero-risk capability: migrate the AdminPilot haptics call
onto `Crosswake.Bridge.push/3`, delete the hand-rolled inline script from BOTH showcase LiveViews,
and evolve the evidence panel so the fail-closed thesis renders itself in a desktop browser.

D-65 is the argument that makes this worth doing properly rather than mechanically. The reader is a
skeptical Phoenix developer running the showcase in a desktop browser, where there is no shell at
all. Today they click Approve and see four fields proving only that Phoenix built an envelope.
After migration the DEFAULT desktop experience becomes the strongest demo in the project — shell
declined, reason `shell_unreachable`, there is no browser substitute for a physical tap so Crosswake
does nothing rather than fake one, and the approval stands. That is the fail-closed thesis rendering
itself, for free, on every visit.

This is D-76's **PR #3**, the last of the three.

Purpose: HRDN-01 is the phase's proof vehicle precisely because haptics is already present in the
shipped closed enum of both native cores (D-01), so the seam is proven with zero new native risk.

Output: both showcase LiveViews on the seam, the evolved panel, the dead JavaScript file deleted
with its false claims, two planning documents amended, and a browser lane that proves the migration
positively.
</objective>
