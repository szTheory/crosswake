Perform the mechanical threadline extraction (THREAD-01) and atomically decouple core's two
compile-time coupling sites onto threadline (THREAD-01/THREAD-02), locking the zero-sibling-dep
invariant at the source level. Create the `packages/crosswake_threadline/` skeleton by cloning the

EEX templates, wrap the two optional-Phoenix modules in `Code.ensure_loaded?` guards, repoint the
`gen.audit` template `app_dir` atom to `:crosswake_threadline`, and remove threadline from core.

Two core coupling sites must be inverted in THIS plan, atomic with the move (core will not compile
otherwise): SITE 1 — freeze `@audit_ledger_support_truth` (which calls
`ThreadlineTelemetry.event_names/metadata_keys/forbidden_metadata_keys` at module-eval, a stale-beam
trap) to `@audit_ledger_support_truth_static` frozen literals; SITE 2 — remove the static
`Crosswake.Threadline.Telemetry.forbidden_metadata_keys()` call from `attach_default_logger/1` by
expanding core's `@baseline_forbidden_keys` with ONLY the curated universal-floor delta (D-5), NOT a
wholesale absorb of threadline's OAuth/passkey minutiae. Core is wired to depend on
`crosswake_threadline` via a test-only `path:` dep so `phase133` (TELEM-04 Side-A, which drives
`Crosswake.Plug.Threadline`) keeps compiling.

This is the direct mechanical analog of Phase 138 Plan 01, PLUS the two-site atomic core decouple
(threadline-novel: threadline is NOT a `:companions` registrant, so Phase 136's registry inversion
never covered it) and the `priv/` tarball requirement (unique among companion packages). There is NO
Finding-boundary refactor (threadline has zero sibling coupling) and NO StubAbsentCompanion (threadline
is not a companion behaviour implementor).

Purpose: This is the irreversible-adjacent structural move. Getting namespace preservation, the
`priv/` inclusion, the two-site atomic decouple, and the zero-sibling-dep invariant right at the
source is what makes the clean-room proof (Plan 02) and the publish gate (Plans 03-04) trustworthy.
Output: standalone crosswake_threadline package (compiles green, ships priv/), core with threadline
removed AND both coupling sites decoupled (compiles green), core wired to the package via test-only
path dep for the dress rehearsal.
