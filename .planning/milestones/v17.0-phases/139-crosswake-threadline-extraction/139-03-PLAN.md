<objective>
Wire the CI publish pipeline (THREAD-03) for crosswake_threadline as an INDEPENDENT release-please
component and make the clean-room lane threadline-correct and vacuity-safe (THREAD-02). Patch
`verify_companion_cleanroom.sh` so the smoke test SUPPRESSES the standard companion-behaviour
assertions (`enabled?/1`, `companion_id/0`, `validate_dependency/0`) for crosswake_threadline —
threadline is NOT a `Crosswake.Companion` implementor and calling those raises
`UndefinedFunctionError` — and substitutes three module-shipment canaries (Telemetry.event_names/0 ==
3, Plug.Threadline.init/1 header, Audit.Ledger.actor_ref/2 hex) so the lane proves REAL threadline
machinery shipped with BOTH siblings absent. Register the component block (one-shot release-as 0.1.0,
NOT in linked-versions), add the manifest entry, add the ~100 lines to release-please.yml (threadline
outputs + publish-hex-threadline + clean-room-proof-threadline + extended
release-as-cleanup/release-failure-alert), add the crosswake_threadline path dep to the example host,
and add the threadline row to the compat matrix.

This is the direct analog of Phase 138 Plan 03 (s/chimeway/threadline/g throughout), with two
threadline-specific differences: (a) the clean-room script must SUPPRESS the companion-behaviour
assertions (chimeway flipped `refute enabled?` to `assert enabled?`; threadline removes them entirely
because it has no companion facade), and (b) the clean-room installs crosswake + crosswake_threadline
with NEITHER sigra NOR chimeway. All jobs key on the per-component `threadline_release_created` output
(never the aggregate `releases_created`), preserving independent, sequential publishing (D-8, D-9).

Purpose: The publish gate chain (Plan 04) depends entirely on these lanes existing and being
green-able. The suppress-companion-assertions fix is the difference between a passing and a
spuriously-failing clean-room-proof-threadline. No real publish happens here — publishing is the
human-gated, DEFERRED Wave 4.
Output: threadline registered as an independent component; 3 new CI jobs; a vacuity-safe, no-engine,
non-companion threadline clean-room smoke path; example-host + compat-matrix updated.
</objective>
