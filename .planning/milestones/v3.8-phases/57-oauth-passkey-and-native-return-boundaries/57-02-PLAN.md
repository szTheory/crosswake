# Plan 57-02: AuthReturn Contracts, Semantic Validation, And No-Smuggling

<objective>
Harden pure Sigra `AuthReturn` contracts so OAuth callbacks, passkey assertions, native deep links, and bridge events are typed evidence envelopes that validate posture before backend promotion, while never carrying authority or raw secrets.
Decision coverage: D-11, D-12, D-13, D-14, D-15, D-16, D-17, D-18, D-19, D-20, D-21, D-22, D-23, D-24, D-25, D-26.
</objective>

<context>
Use the existing `Crosswake.Companions.Sigra.AuthReturn` module if present. Treat envelope validation as shape, posture, and comparison support only; it must not become self-contained session authority. Core remains pure Elixir and does not depend on Ecto, Plug.Conn, provider SDKs, WebAuthn libraries, or Phoenix session mutation.
</context>
