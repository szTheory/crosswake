## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-54-05 | Elevation of Privilege | `Crosswake.Policy.Schema` / `Crosswake.Policy.Route` | mitigate | Require explicit `auth_posture` values and default sensitive routes to `:strict_recent` per D-13 and D-14. |
| T-54-06 | Tampering | `Crosswake.Policy.Route.validate_*` | mitigate | Cross-check `:cached_read_only_ok` against route metadata so non-read-only or authority-promotion routes fail closed per D-16. |
| T-54-07 | Information Disclosure | manifest fixtures | mitigate | Serialize posture only; do not serialize session ids, freshness evidence, tokens, or any runtime authority payload into manifest output. |
| T-54-08 | Scope Creep | policy surface | mitigate | Reject new handoff, step-up, OAuth, passkey, or provider-return route fields in this phase; only `auth_posture` is added. |
</threat_model>
