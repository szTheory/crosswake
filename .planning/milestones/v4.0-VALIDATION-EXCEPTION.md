# v4.0 Validation Ledger Accepted Exception

v4.0 shipped before the project adopted per-phase `*-VALIDATION.md` ledgers and
before phase directories were archived under
`.planning/milestones/v4.0-phases/`. Creating synthetic ledgers for phases 64
through 69 now would make the archive look more precise and more contemporaneous
than it actually was.

This artifact is the terminal validation-ledger record for that narrow
historical gap. The authoritative v4.0 evidence remains the shipped closeout
contract, the milestone audit, the archived requirements snapshot, and the
Phase 69 docs-contract parity proof cited in frontmatter.

This mirrors the established `v3.6-VALIDATION-EXCEPTION.md` precedent for the same
class of pre-ledger-system milestone.
