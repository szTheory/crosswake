## Overview

v18.0 made Crosswake's package-family release path automated, path-specific, and honest before adding new product breadth. It harvested SEED-003 and SEED-004 by enforcing exact Release Please component gates, guarded CI publishing and recovery, exact-version published-core clean-room proof, iOS mirror preflight/backfill guardrails, decoupled native proofs, and a local/JSON/advisory-live release-status operator surface.

## Outcomes

- Companion-only releases cannot publish core Hex, iOS mirror, or Android Maven artifacts.
- The clean-room harness resolves the exact package under test against its real published-core floor.
- Maintainers can run `mix crosswake.release.status` for local package-family release status and `--json` for automation.
- Missing or invalid iOS mirror credentials fail with a clear action instead of leaving SwiftPM silently behind.
- Deferred product-breadth seeds remain out of scope until release integrity is trustworthy.

## Milestone Summary

**Key Decisions:**

- Gate release publishing by exact component/path identity, not aggregate Release Please outputs.
- Keep package publishing CI-owned on the happy path, with exact-ref/idempotent recovery only.
- Treat live registry checks and real mirror mutation as optional/advisory external state.

**Issues Resolved:**

- SEED-003: iOS mirror-token and missing `v0.2.0` tag now have fail-fast preflight and a guarded verify-first backfill path.
- SEED-004: companion clean-room proof now derives real core floors and installs exact published companion versions.
- AUTO-03 cleanup: manual Hex recovery now rejects bare semver tag refs and accepts only full SHAs or package-scoped Release Please tags matching the selected package/version.

**Issues Deferred:**

- DASH-01 `crosswake_dashboard`, SYNCP-01 offline-sync productization, NTV-01 native disk budgets, and SEED-002 capability/commerce breadth remain next-milestone candidates.
- Branch-protection registration remains an admin-gated detect/report surface; v18 does not self-apply repository settings.

**Technical Debt Incurred:**

- None inside the v18 milestone scope.

**Residual External Risks:**

- Real iOS mirror mutation still requires a correctly scoped maintainer `MIRROR_PUSH_TOKEN`.
- Live registry probes remain advisory; normal CI stays local/read-only by design.
