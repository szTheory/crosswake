  <behavior>
    - Resolving against a route without `notification_open` returns `{:error, %Shell.Denial{reason: :notification_open_denied, code: "notification.open.policy_denied"}}`.
    - Resolving against a route with an unpermitted `action_ref` returns `unsupported_action`.
    - Calls `intent_consumer.consume_intent/1`. Invalid intent consumption variants like `:expired`, `:replayed`, `:binding_mismatch`, and `:revoked` return their corresponding specific denial codes.
    - Successful pre-flight calls `RouteGate.evaluate` and returns its `Decision` (or passes through its `Denial` like `:step_up_required`).
  </behavior>
  <action>
    Create `Crosswake.Companions.Chimeway.Resolver`.
    Implement `resolve/3` taking `Manifest.Root`, `NotificationOpenEvidence`, and an `intent_consumer` module (which implements `Crosswake.Companions.Chimeway.IntentConsumer`).
    Explicitly reference the analog `lib/crosswake/companions/sigra/evaluator.ex` from `61-PATTERNS.md` and use the Denial Packaging Pattern detailed below.

    Flow: 
    1. Look up `route_id` in manifest. If absent, fail `route_mismatch`.
    2. Read `route.notification_open`. If falsy, fail `policy_denied`.
    3. If `notification_open` restricts actions (`[actions: [...]]`), verify `evidence.action_ref` is allowed. If not, fail `unsupported_action`.
    4. Call `intent_consumer.consume_intent(evidence)` to orchestrate the state checks. If it returns `:expired`, `:replayed`, `:binding_mismatch`, `:revoked` or otherwise not `:valid`, generate the appropriate core denial (e.g. `notification.open.expired`, `notification.open.binding_mismatch`, `notification.open.binding_revoked`).
    5. Delegate to `RouteGate.evaluate(manifest, route_id, target, activation_source: :notification, auth_context: evidence.auth_context)`.
    6. Return the `Decision` or pass-through the `Denial` unmodified. (Decisions D-07, D-08, D-10, D-11, D-12)

    Denial Packaging Pattern Excerpt:
    ```elixir
    # Follow this pattern from Sigra's evaluator but adapt for NotificationOpenEvidence
    defp deny(%RouteEntry{} = route, code, details, opts) do
      sanitized =
        details
        |> Map.put_new(
          :evaluated_at,
          DateTime.utc_now() |> DateTime.truncate(:second) |> DateTime.to_iso8601()
        )
        |> DenialCodes.sanitize_details()

      {:deny,
       Denial.new(
         reason: :notification_open_denied,
         code: code,
         message: @generic_message,
         route_id: route.id,
         details: sanitized
       )}
    end
    ```
