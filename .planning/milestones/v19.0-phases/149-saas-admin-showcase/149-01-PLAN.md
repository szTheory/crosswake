Phase 149 uses ASVS L1 as the security baseline with a high-severity blocking threshold. Any implementation that introduces a high-severity ASVS L1 issue in authentication, session management, authorization, validation, business logic, error handling, or support-truth disclosure must stop execution and revise before the plan can be marked complete.

</threat_model>
