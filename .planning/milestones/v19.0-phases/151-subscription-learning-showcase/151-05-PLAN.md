|----------|-------------|
| Context read models -> LiveViews | Domain state crosses into learner-facing UI. |
| Route diagnostics -> product UI | Support truth appears inside product pages. |
| Review event projection -> history | Server-confirmed events become user-visible progress evidence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-151-20 | Information Disclosure | LearnLoop LiveViews | mitigate | Render fictional fixture data only; no raw tokens/provider payloads/session refs. |
| T-151-21 | Product Safety | cached read-only pages | mitigate | Components and tests require visible cached read-only labels and no local mutation controls. |
| T-151-22 | Spoofing | sync ledger UI | mitigate | Copy distinguishes saved locally/queued/synced/rejected and routes mutation only to socketless island. |
| T-151-23 | Denial of Service | responsive UI | mitigate | CSS wraps badges/actions and avoids horizontal overflow on mobile. |
| T-151-SC | Tampering | package installs | accept | No package-manager install tasks exist in this plan. |
</threat_model>
