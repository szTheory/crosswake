## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Deterministic fixtures -> product UI | Fixture copy can overclaim offline, native storage, or entitlement support. |
| Server reset -> browser state | Server reset can misrepresent browser-owned IndexedDB/outbox cleanup. |
| Review events -> history read model | Persisted sync evidence is displayed as progress/history. |
