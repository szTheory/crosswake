## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser offline island -> sync API | Browser-owned queued review events cross into server validation. |

Phase 151 uses ASVS L1 with a high-severity blocking threshold. Entitlement fail-closed behavior, socketless offline ownership, idempotent outbox replay, support-truth copy, and reset/browser-state honesty are in scope for this plan.
