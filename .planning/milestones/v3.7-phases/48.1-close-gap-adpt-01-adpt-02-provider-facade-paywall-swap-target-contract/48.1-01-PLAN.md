<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LiveView -> storefront adapter | Untrusted runtime configuration selects the module and provider facade path for purchase/restore events. |
| storefront adapter -> provider evidence normalizers | Provider-specific metadata is transformed into shared reconciliation evidence and must not leak authority semantics. |
| reconciliation attempt -> entitlement projection | Storefront evidence crosses from pending ingest into authoritative backend projection and must not grant access early. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-48.1-01 | Elevation of Privilege | `PaywallEntryLive`, `ReconciliationInbox`, `EntitlementProjection` | mitigate | Keep adapter callbacks evidence-only, require `attempt.status == :awaiting_verification`, and prove `:granted` only after `MockBackend.build_verified_snapshot/2` and `EntitlementProjection.project_snapshot/2` per D-03, D-11, and D-16. |
| T-48.1-02 | Tampering | `ProviderAdapterStorefront` provider selection | mitigate | Read `Application.get_env(:crosswake_example, :paywall_storefront_provider, nil)`, accept only `:storekit | :play_billing`, return `{:error, :provider_not_configured}` or `{:error, {:invalid_provider, provider}}`, and prove there is no fallback to mock per D-05 through D-09. |
| T-48.1-03 | Denial of Service | storefront adapter contract surface | mitigate | Add `CrosswakeExample.Commerce.StorefrontAdapter` behaviour, require `@behaviour` on both adapters, and add proof/docs-contract assertions that the facade exports `simulate_purchase/1` and `simulate_restore/1` before it is used as `:paywall_storefront_adapter` per D-01, D-02, D-10, and D-12. |
| T-48.1-SC | Tampering | package-manager installs | accept | No new package-manager dependencies or install tasks are allowed in this phase; keep the closure inside existing Elixir/Phoenix code and tests. |
</threat_model>
