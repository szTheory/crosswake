| Explicit wrapper modules | Configure `StoreKitStorefront` or `PlayBillingStorefront` directly as the adapter. | |
| Closed facade with wrapper delegation | Keep one ergonomic facade swap target, use closed provider config, delegate to explicit provider-owned wrappers/branches. | x |

**User's choice:** Agent recommendation accepted by instruction: one cohesive recommendation set.
**Notes:** Research favored the closed facade with explicit delegation because it keeps provider ownership outside the LiveView, avoids hidden platform inference, matches runtime config patterns in Phoenix apps, and still gives adopters a simple one-module swap target.
