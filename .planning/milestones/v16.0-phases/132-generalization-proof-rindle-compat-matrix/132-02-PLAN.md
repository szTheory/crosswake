<objective>
Ship the cross-package compatibility matrix doc (`guides/companion_compatibility.md`,
COMPAT-02) and the merge-blocking drift test that keeps it honest against each
companion's declared `{:crosswake, "~> ..."}` requirement (COMPAT-03). The doc is
code-canonical-with-drift-test (Keathley/Oban idiom): the companion `mix.exs` is the
source of truth, the doc is human-readable, and the test asserts parity bidirectionally.

This plan depends on 132-01 only for the existence of `packages/crosswake_rindle/mix.exs`
(so the non-vacuity guard counts >= 2 packages). It does NOT touch any core lib/ or
moved tests, so it runs in parallel with the extraction plan (132-03) in Wave 2.

Purpose: Give adopters a single source of truth for "what core version + which engine
do I need to add crosswake_<x>?" and make drift mechanically impossible to merge.
Output: `guides/companion_compatibility.md` + `phase132_compat_matrix_drift_test.exs`.
</objective>
