<objective>
Establish the ONE distribution mechanism — vendor the packaged `priv/static/crosswake/tokens.css` (from Plan 01) by verbatim copy + `<link>` — in both consumers: the `crosswake.gen.offline_ui` generator (for external Phoenix hosts) and the in-repo example host. The generator copies the file with the existing `ensure_file` no-clobber guard and adds a `<link>` for it before `app.css` in the generated root layout. The example host (which serves `/css/`, not `/assets/`) gets a manually-vendored byte-identical copy and a matching `<link>` in both LiveViews. The generator test is extended to assert the copy and the link order.

Purpose: Wire NORM-03's single documented distribution mechanism so both consumers receive tokens.css the same way — by copy + link — with no hand-edited palette anywhere. This is the contract Phase 108 rewires consumers against.
Output: Extended generator task + template, vendored example-host copy + links, extended generator test.

Scope fence: Phase 107 establishes the link/copy CONTRACT only. Do NOT rewire template body classes (`bg-cw-foam-50 text-cw-current-950`), do NOT touch `examples/phoenix_host/assets/css/app.css`, do NOT remove the stale Tailwind theme in the generator — those are Phase 108.
</objective>
