<objective>
Give the checked-in Android host (`examples/android_shell_host`, `dev.crosswake.shell`)
an additive dev product flavor: an env flavor dimension with prod (proof/default) and
dev flavors, a dev source-set overlay (manifest + network-security config + the
generated dev asset), and a network-security config permitting cleartext only for
10.0.2.2 (D-06..D-09). Migrate the two examples/-path Gradle invocations the flavor
rename breaks (D-10 blast radius). The prod manifest/assets stay byte-untouched.

Purpose: AGP forces every variant to carry a dimension once any flavor exists, so the
proof build needs an explicit `prod` flavor; the dev overlay is the idiomatic
source-set mechanism with no library/API change. networkSecurityConfig takes precedence
over inline usesCleartextTraffic and is scoped per-domain so prod cleartext stays off.

Output: flavor block in build.gradle; dev AndroidManifest.xml + network_security_config_dev.xml;
migrated verify script + QUICK_START walkthrough Gradle tasks.
</objective>
