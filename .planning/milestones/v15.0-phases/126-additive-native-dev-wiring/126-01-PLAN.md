<objective>
Extend the existing `mix crosswake.contract.gen` task with a `--dev` flag that
generates and commits the two dev activation fixtures (iOS, Android), then guard
them with a separate dev-drift assertion. This is the single source of truth
(D-11/D-12/D-13) that the native overlays (Plans 02, 03) and the proof-posture
guard (Plan 04) depend on.

Purpose: Hand-authored fixtures rot silently when the contract bumps; generation
keeps `bridge_protocol_version` + capabilities in lockstep so only url / origin ever
diverge from prod.

Output: `--dev` flag + dev builders + path constants on the generator; two committed
dev fixtures; `@dev_generated_json_paths` + a dev-drift test in
`contract_drift_test.exs`.
</objective>
