<objective>
Reconcile the native bridge compatibility checks to a single `>=` min-version-floor semantics that mirrors Elixir's `compatible_version?/2`, killing the exact-equality denial footgun across BOTH native packages, at ALL four fix sites, on ALL three version axes plus capability + pack versions. Pin the port behaviorally with new floor conformance vectors generated from the canonical source.

Purpose: An additive protocol/runtime bump currently makes an older native shell silently DENY a valid request because the native check is `==`. Elixir already floors all three axes; this brings native into line so `shell_provides >= manifest_demands` allows the request, while a genuinely-older shell still fails closed. This is COMPAT-01 and the single most load-bearing fix of the milestone.

Output: Two hand-ported `SemVer` helpers (zero native deps), five fix-site conversions, and new allow+deny floor vectors for every floored axis.
</objective>
