## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser test to Phoenix host | Playwright drives untrusted browser behavior against the test Phoenix server. |
| Test-only E2E routes | `/_e2e` inspection routes must remain test-only and compile out of prod. |
| CI artifact output | Screenshots can be misread as correctness proof unless captions and summaries label them as collateral. |

| T-120-01-02 | Spoofing | `/bridge-proof` semantic payload | mitigate | Assert route id, active route id, protocol, command, capability, origin, and correlation id rather than trusting visible copy. |
