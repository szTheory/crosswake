<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CI runner to native tools | Platform-specific tooling availability varies and must not silently change support truth. |
| Native artifact to public reader | Simulator/emulator output can be overread as physical-device support. |
| Native host coordinates | Checked-in public-coordinate proof must remain distinct from local-dev proof and generated public-coordinate proof. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-120-03-01 | Spoofing | Native collateral labels | mitigate | Manifest and docs tests enforce proof class, coordinate mode, execution environment, and action status separately. |
| T-120-03-02 | Repudiation | Native capture attempts | mitigate | Manifest records command, commit SHA, captured-at, status, and unavailable reason. |
| T-120-03-03 | Elevation of Privilege | Native evidence claims | mitigate | Guards reject physical-device, camera/media, provider-authority, app-store, and merge-blocking claims from advisory evidence. |
| T-120-SC | Tampering | npm installs | mitigate | Helper uses Node built-ins; no new package-manager dependency is planned. |
</threat_model>
