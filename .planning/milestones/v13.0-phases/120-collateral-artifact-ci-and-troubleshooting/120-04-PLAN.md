<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Doctor output to human docs | Structured findings become user-facing recovery instructions. |
| Evidence labels to troubleshooting readers | Users may treat advisory evidence as support unless the guide states limits. |
| README/ExDoc navigation | First-read docs can accidentally widen Crosswake's route-policy thesis. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-120-04-01 | Spoofing | Troubleshooting labels | mitigate | Docs scanner enforces canonical findings, support labels, owner, command, and limitation coverage. |
| T-120-04-02 | Information Disclosure | Troubleshooting examples | mitigate | Use demo/error vocabulary and avoid backend internals unless needed for route-owner remediation. |
| T-120-04-03 | Elevation of Privilege | Recovery instructions | mitigate | Entries keep provider/device/native evidence non-authoritative and map authority back to route owner/backend where applicable. |
| T-120-SC | Tampering | package installs | accept | No npm/pip/cargo install is planned in this docs/test plan. |
</threat_model>
