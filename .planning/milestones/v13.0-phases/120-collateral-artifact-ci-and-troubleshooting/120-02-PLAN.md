## must_haves decision coverage index

- D-07: evidence uses one run-level `evidence-manifest.json` with route-level entries.
- D-08: every route entry carries Crosswake version, commit SHA, route id, runtime owner, platform/runtime, command, proof class, support label, coordinate mode when relevant, source job, captured-at timestamp, artifacts, retention label, and known limitations.
- D-09: required browser artifacts fail closed when missing, while advisory native unavailable states are explicit.
- D-10: reports, traces, videos, screenshots, and logs remain bounded CI artifacts.
- D-11: committed docs assets stay limited to a small curated screenshot/manifest set when needed.
- D-12: ExUnit validates manifest keys, labels, route ids, limitations, and missing-artifact failure semantics.
- D-13: job summaries link manifest and artifacts in adopter-readable proof/capture/advisory/non-claim language.
- D-19: manifest and caption vocabulary stays shared across browser and native artifacts.
- D-29: evidence captions expose route id, runtime owner, proof class, support label, command, result, and limitation.
- D-30: Mix/ExUnit owns manifest validation and GitHub Actions owns artifact retention/upload.
- D-31: committed collateral remains readable and actual-state-first.
- D-32: manifest validation failures name the missing field or artifact.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Playwright output to manifest | Test output becomes adopter-facing evidence metadata. |
| CI artifact bundle to reader | Uploaded artifacts can be interpreted as proof claims. |
| Committed docs assets | Curated collateral enters the public repository and HexDocs-adjacent surfaces. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-120-02-01 | Tampering | `evidence-manifest.json` | mitigate | ExUnit validator enforces required fields, labels, artifact existence, retention, and known limitations. |
| T-120-02-02 | Repudiation | CI evidence source job | mitigate | Manifest includes `commit_sha`, `source_job`, `captured_at`, command, route id, and proof class. |
| T-120-02-03 | Information Disclosure | Committed collateral | accept | Commit only small demo screenshots/manifests without secrets or user data; rich outputs stay bounded in CI. |
| T-120-SC | Tampering | npm installs | mitigate | Use existing lockfile and no new package-manager dependency. |
</threat_model>
