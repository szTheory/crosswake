## Trust Boundaries

| Boundary | Description |
|---|---|
| automation -> JSON output | CI and issue tools consume machine fields and must not scrape prose. |
| CLI args -> Mix task | `--json` and `--live` are strict public options; invalid args are untrusted input. |
