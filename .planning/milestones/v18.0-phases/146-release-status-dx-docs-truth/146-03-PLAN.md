<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Mix task -> public registries | `--live` reaches Hex, Maven Central, and GitHub SwiftPM mirror endpoints over the network. |
| Registry/tool failure -> status output | Network failures must not be reported as artifact absence. |
| Docs -> operators/adopters | Public docs shape operator behavior around read-only status, compatibility floors, and guarded mutation paths. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-146-10 | Tampering | live registry probes | mitigate | `--live` probes read exact endpoints/refs only and never call publish/push/backfill/tag mutation commands. |
| T-146-11 | Information Disclosure | live probe output | mitigate | Output only concise source/status/url/ref/next_action; do not print tokens, raw payloads, stack traces, or long curl/git logs. |
| T-146-12 | Denial of Service | live network calls | mitigate | Keep default local-only; bound curl with `--max-time`; configure git probes to avoid interactive prompts and report `unavailable` on failure. |
| T-146-13 | Tampering / Reliability | false absence from outage | mitigate | Model `missing` separately from `unavailable`; only exact 404/successful empty-ref checks become `missing`. |
| T-146-14 | Spoofing | compatibility floor docs | mitigate | Keep `guides/companion_compatibility.md` as floor authority and do not infer floors from registry presence. |
| T-146-SC | Tampering | package installs | mitigate | No new package-manager installs are planned; live probes use existing curl/git and tests use injected functions. |
</threat_model>
