## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Release Please outputs to publish jobs | Release identity crosses from release automation into registry mutation authority. |
| GitHub Actions runner to Hex.pm | CI uses `HEX_API_KEY` to publish immutable Hex artifacts. |
| Workflow logs to operator | Logs expose package/ref/version state without exposing secrets or misleading proof state. |
| Local package source to public registry | Helper validates local package identity before irreversible registry mutation. |
