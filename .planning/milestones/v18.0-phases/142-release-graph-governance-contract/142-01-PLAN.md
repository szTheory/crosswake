## Trust Boundaries

| Boundary | Description |
|---|---|
| Release Please outputs -> GitHub Actions jobs | Release identity data controls publish, mirror, proof, cleanup, and alert jobs. |
| GitHub concurrency scheduler -> release workflow | Platform scheduling can cancel or replace release work unless the workflow opts out. |
| Cleanup job -> protected main | Cleanup can mutate release config only by opening a PR branch, not by direct protected-branch mutation. |
| GitHub secrets -> shell steps | Publish and mirror tokens must not leak through shell output or unquoted expansions. |
