### E2E Flows Verified

1. **Cold start thread mint:** iOS/Android `ActivationCoordinator` mints UUID on cold start → carried through `ActivationRequest.threadID` → persists across deep_link/notification/in_app_navigation
2. **HTTP header injection:** Native shell injects `X-Crosswake-Thread-Id` on WebView `loadUrl`/`URLRequest` → Plug reads (`:inbound`) or falls through to mint (`:minted`)
3. **Server Logger.metadata:** Plug sets `Logger.metadata(crosswake_thread_id: id)` + echoes response header + emits telemetry start/stop/exception — guide documents correct read-path via `Logger.metadata()[:crosswake_thread_id]` (WR-03 fixed)
4. **LiveView WebSocket bridge:** `on_mount` reads `_crosswake_thread_id` from connect params → sets process metadata (no minting; WebView gap documented in DOCS-03)
5. **Durable ledger path:** host runs `mix crosswake.gen.audit` → `record_in_multi/3` inside `Ecto.Multi` → append-only audit event persisted (guide documents correct `/3` arity, WR-02 fixed)
6. **Operator query:** `mix crosswake.threadline --thread-id <id>` → chronological sort → ephemeral or durable posture tree
7. **Doctor posture check:** `mix crosswake.doctor` → `phase_95_threadline_findings/2` emits 4 findings including fail-closed PII `:error`
8. **Guide parity enforcement:** `guides/threadline.md` → 23-assertion hermetic parity test (21 original + 2 WR-02/WR-03 regression guards) → merge-blocking CI gate blocks on any contract string drift

### Integration Warnings (non-blocking, pre-existing)

**WARNING-1:** Doctor reads `forbidden_metadata_keys` via `SupportMatrix.audit_ledger_support_truth()` (compile-time embedded constant in `support_matrix.ex`) rather than a direct call to `Threadline.Telemetry.forbidden_metadata_keys/0`. Stale `.beam` could mask drift until clean build. Mitigated by `support_matrix_test.exs:287–290` which cross-checks at runtime. Affects PROP-02, OPER-02.

**WARNING-2:** `Crosswake.Plug.Threadline` applies no format validation on inbound `thread_id` — any string ≤128 chars passes through to `Logger.metadata` and telemetry. Malformed native UUIDs propagate silently. Intentional design scope (PROP-01 says "reads verbatim") but leaves no rejection path for garbage values. Affects PROP-01, PROP-05.
