## Capability Delivery

- [x] **CAP-HAPTICS**: Implement low-frequency `haptics` bounded bridge support across host contract truth and native shells.
- [x] **CAP-SHARE**: Implement semantic `share` bounded bridge support without exposing generic WebView-native authority.
- [x] **CAP-APPINFO**: Implement read-only `app_info` support for native app metadata.
- [x] **CAP-DEEPLINK**: Implement deep-link activation truth that distinguishes inactive routes from routes that reject external entry.
- [x] **CAP-PERMSTATUS**: Implement read-only `permissions.status` support scoped to the `notifications` alias.
- [x] **CAP-NOTIFTOKEN**: Implement provider-tagged `notification_token` evidence without inventing backend entitlement or delivery truth.
- [x] **CAP-FILEPICKER**: Implement transfer-bound `file_picker` support with copy-first staged handles and typed cancellation.
